# library/ — 收集信息素材库

> 这是什么：kfmv4 的**收集信息库**。存放从外部收集来的素材——剪藏的文章、网页、
> 链接、调研笔记、金句、参考资料等，未来持续追加。
> 别的去哪找：实验与行为观察 → `experiments/`；跨线评审信件 → `docs/ledger/agent-inbox/`；
> 语义巡逻结论 → `docs/ledger/semantic-chain-inbox.md`。

## 定位（为什么单独建库）

项目里已有的「信箱」都是专用通道，不适合存外部素材：

| 通道 | 装什么 | 为什么不装收集素材 |
|------|--------|--------------------|
| `docs/ledger/agent-inbox/` | 跨线评审往来信 | 是设计评审通信面，不是资料库 |
| `docs/ledger/semantic-chain-inbox.md` | 巡逻逐轮结论 | 机器自动写入，append-only 日志 |
| `experiments/` | 实验 / 行为观察 | 研究文件夹，契约型实验 + 研究笔记，不是剪藏库 |

本库是**存类**资料（为了万一/参考），可检索但不占执行者注意力；被频繁读时再升读类。

## 目录地图

| 目录 | 是什么 |
|------|--------|
| `collected/` | 剪藏/外部素材（一素材一文件：文章正文、网页摘录、参考资料） |
| `notes/` | 研究笔记（`library/notes/harness-studies/`：由 `experiments/harness-studies/` 迁入收藏，2026-08-21） |

## 收录规则

- **一素材一文件**：每个剪藏/文章一个 `.md`，正文完整，别拆散成片段。
- **命名**含主题 + 日期 + 来源：`<主题>-<YYYY-MM-DD>-<来源>.md`。
- **头部写明出处**：文首引用块记原文标题 / 作者 / 发布时间 / 原文链接，人读即机读。
- **append-only**：素材归档后不改原文正文；有补充写为追加段并标注日期。
- **可再生垃圾不进库**：不可再生成的原始载体（PDF 等大文件）指向外部来源，
  库内只留可读正文。
