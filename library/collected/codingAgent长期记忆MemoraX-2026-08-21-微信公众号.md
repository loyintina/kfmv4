## 痛点（文章出发点）

用 Claude Code/Codex 做项目迭代：Agent 各自单任务能力越来越强，但
**一开新对话一切归零**——前一天聊清的权限架构、被否决的方案、版本
兼容约束，重开全丢；同一坑重踩、被否的方案重提、老问题从头查。
即便不换 Agent，**上下文压缩后关键约束照样丢**。

关键洞察：强行拉大上下文窗口不解决——它存下所有对话，但**分不清哪些
是无效调试垃圾、哪些是决定后续重构的核心工程约束**。

## MemoraX Code 是什么

https://github.com/memorax-ai/memorax-code

给 Coding Agent 加**项目记忆层**，跨会话、跨不同 Agent，新对话不用
反复复述背景。两套存储：

- **MemoraX Local（本地记忆）**：针对代码仓库——代码结构、关键入口、
  Issue 历史、项目演进；
- **MemoraX Cloud（云端记忆）**：跨任务/对话/Agent 的项目经验、开发
  偏好、失败方案，支持团队共享。

新任务不来塞全部历史，**基于意图检索**，只喂当前任务相关的记忆。
（Codex 做完换 Claude Code，沉淀的项目认知仍生效。）

## 可学习记忆框架

比人工提示词/硬编码规则更进一步：构造代码训练数据集 + 记忆评估与奖励
信号，让记忆模型自己学「什么该留、什么过时、何时召回」。训练与用户
私有记忆数据隔离，模型能力迭代后服务线上任务。

## Procedure Memory：自动沉淀可复用工程经验

文章最看好的一块。从历史开发轨迹自动提取有复用价值的 **分析/执行/
验证步骤**，提炼成结构化 Skill 经验供同类任务复用。不是记录「上次
发生了什么」，而是总结「这类问题哪些路径/步骤/验证有效」。

官方实验：123 个历史片段 → 自动提炼 15 条工程经验 → 4 类 Procedure
Memory → 3 小时复杂长程任务对比：

| | 综合得分 | 关键检查项通过 |
|---|---|---|
| 不开启记忆 | 11.71 | 2/13 |
| 开启 Procedure Memory | 70.30 | 10/13 |

调用成本还降约 22.6%（不记忆时 token 大量耗在重复摸索踩过的坑上）。

适可而止：记忆不是越多越好。内部数据：85.5% 记忆触发与人的判断一致，
81.2% 记忆内容获正向反馈——只在合适时机弹正确的历史。

## Benchmark 与适配

- AML（Agent Memory Leaderboard）Coding Track **62 分位列第一**，对比
  Claude Mem 解题率提升 10%；
- 原生支持 **Codex / Claude Code / Deepseek Harness / OpenCode** 四款
  Coding Agent（注意：Deepseek Harness 即 kfm 用的 dsh 类型，已在列）；
- 官网 code.memorax.net / 记忆平台 platform.memorax.net；
- 开发者可在官方平台查看/编辑/删除自己的记忆。

## 文章结论

「模型能力决定一次任务能走多远，**记忆系统决定下一次任务从哪里
开始**。」真实软件工程是反复迭代、同类问题重来、多 Agent 切换；
代码不记录团队踩的坑、被否的方案、版本兼容隐性约束——这些隐性工程
知识恰是长期项目最宝贵的东西。

## 与 kfm 的对照（评审会话 · 2026-08-21 剪藏附注）

1. **痛点是同一个**：kfm 的多线协作一直在和「上下文压缩丢约束」搏斗
   ——信箱的七字段机读头、评审链、代际戳、迁徒总账，本质都是**把隐性
   工程约束外置成文档**这一派做法（记忆在文档体系，不在模型权重）。
   MemoraX 是另一派：**记忆进模型**（意图检索召回）。两派互补而非互斥：
   kfm 的文档账可检索但靠手工流转，MemoraX 可学习召回但读不到 kfmv4
   的评审纪律。理想形态 = kfm 的文档真相源 + 可学习检索层。
2. **Procedure Memory 的「分析/执行/验证步骤提炼」与 kfm 的评审-链路
   纪律同构**：kfm 的 874/875/882 评审链、链红入仓教训、git 卫生 v0，
   正是人工提炼的「可复用工程经验」。MemoraX 把它自动化了——值得跟踪
   它「123 片段→15 条经验」的提炼质量，看是否值得在 kfm 内试套。
3. **适配表点名 Deepseek Harness（dsh）**——kfm 线（dsh）是被官方原生
   支持的目标类型之一，未来若做 agent 集群记忆层，MemoraX 是现成候选。
4. **caveat**：文章是产品宣传口径，61→62 benchmark 数字、85.5% 判断
   一致等均为官方数据，未独立验证；「可学习」的具体评估/奖励信号设计
   也没贴出来。当参考不当定论，落地前必须 t 检记忆召回误报率（8 月内
   kfm 自己踩过「乱召回过时经验」等价问题的影子）。
