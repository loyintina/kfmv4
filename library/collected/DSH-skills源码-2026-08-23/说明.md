## 这是什么

DeepSeek Harness 的 `.agents/skills/` 原始目录，11 个 skill 完整 vendor。
旷野那篇知乎回答分析的核心对象，就是这批 documents。特征（旷野的概括）：

- **从"执行者会偷懒/作弊/糊弄"前提出发**，篇幅重在"堵糊弄事的路"而非"教做事"
- 大量**反向/否决/降级**判断（"Reject or downgrade when..."），而非正向指令
- 把 API 设计品味写成**可执行判据**
- 语义正确性 + 防御性模式 + 质量门禁，向 `.agents/notes/` 化石层回写 Agent Note

## 11 个 skill 清单

| skill | 用途 |
|---|---|
| `dsh-code-review` | PR 代码审查：追踪接口两侧，实现 vs PR 描述 vs Agent Note（错误/取消/所有权/销毁四维）；经典 API 膨胀判据 |
| `dsh-find-simplifications` | 找精简候选 → 写证据背书的 Agent Note；三类语料（生产/非生产/模糊）；knip 不可当结论 |
| `dsh-trim-cot-leakage` | CoT 泄漏检测（旷野提到） |
| `dsh-prose-standard` | 文字标准 |
| `dsh-doc-standards` | 文档层级/教程分离标准 |
| `dsh-doc-site-sync` | 文档站同步 |
| `dsh-translate-docs` | 文档翻译 |
| `dsh-pre-push-checks` | push 前检查 |
| `dsh-archive-agent-notes` / `dsh-merging-stacked-prps` | Agent Note 归档 / 堆叠 PR 合并 |
| `record-browser-gif` | 录制浏览器 GIF |

## 与 kfmv4 的关系

这套 skills 是"skill 本质"讨论的**外部最高完成度实证**——正向指令模型本来就会，
价值全在反向判据 + 回写 `.agents/notes/`（决策化石层、带否决理由/备选方案/封印）。
kfmv4 的心法/check 门正是同一哲学的本地化。
