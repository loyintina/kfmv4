# 用户急了

用户对你反复出现的行为模式感到沮丧。

你要做的：创建一条时间旅行流规则（TTSR），它会在此对话更早的节点拦截到问题行为。

规则格式：
- `name`：kebab-case 名称
- `description`：一句话摘要
- `condition`：JavaScript 正则表达式（一个或数组），匹配你刚才产生的问题输出
- `scope`：逗号分隔的范围列表。`text`=助理文字输出，`thinking`=隐藏推理，`tool`=所有工具参数，`tool:edit(*.ts)`=特定工具+路径 glob
- `body`：说明正确行为的 Markdown 引导

约束：
- 精确匹配具体的问题输出——不要用宽泛的通配符
- scope 尽量窄。同一个坏行为出现在工具和文字两个范围时才同时包含两者
- 输出纯 JSON，不放代码块
- 正则反斜杠只转义一次 JSON：`"\\beval\\s*\\("`，不是 `"\\\\beval\\\\s*\\\\("`
