# read — 文件读取

读取文件、目录列表、图片、文档、URL 等。通过 `path` 指定目标，通过 `selector` 指定行范围。

## 参数

- `path`（必填）— 文件路径
- `selector`（可选）— 行范围选择，不用加 `:` 前缀

## 行选择器

- 不指定 → 从头读取（最多 200 行）
- `"50"` / `"50-"` → 从第 50 行开始
- `"50-200"` → 第 50-200 行（含首尾）
- `"50+150"` → 从第 50 行起 150 行
- `"5-16,960-973"` → 多段范围
- `"raw"` → 原样输出，不加行号和锚点
- `"2-4:raw"` → 范围 + 原样

## 支持的格式

- **文本文件**：直接读取
- **目录**：列出目录项
- **图片**：PNG/JPEG/GIF/WEBP → 内联预览
- **压缩包**：`.tar`/`.tar.gz`/`.tgz`/`.zip`，用 `archive.zip:path/inside` 读成员
- **文档**：PDF/Word/PowerPoint/Excel/EPUB → 提取文本
- **URL**：网页、GitHub issues、JSON API 等 → 干净文本/Markdown

## 关键规则

- 绝对不要用 `ls` 或 `find` 列举文件 → `ls` 用 read 读目录，`find` 用 glob 工具
- 独立读取应并行执行
- 路径中有冒号时，用 `selector` 字段而不把选择器拼在路径里
- 超过 1MB 的文件自动截断
