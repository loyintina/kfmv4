# read — 文件读取

读取**文本文件**内容。通过 `path` 指定目标，可通过 `path` 内嵌的 `:行号` 选择器指定行范围。

> 能力边界：仅本地文本文件（UTF-8）。**不支持**目录列表、图片预览、压缩包、
> PDF/Word/Excel、URL——传目录会报 EISDIR 错误，二进制文件会被当文本解码。
> 看目录用 glob/read 读目录前先 ls；图片/文档/URL 无专用工具。

## 参数

- `path`（必填）— 文件路径，支持 :行号 选择器（如 src/index.ts:50-100）；传目录会报错（EISDIR），看目录请先用 ls/glob
- `raw`（可选，布尔）— 设为 true 跳过采样，全量读取

## 大小路由

- `<100KB` → 正常全读
- `≥100KB` → **自动采样**：只读文件头部，输出前 30 行 + 文件信息，并提示补读方式
- 传 `raw=true` 或 `:行号` 选择器 → 跳过采样

## 行选择器

- 不指定 → 从头部读取（小文件全量；大文件采样）
- `"50"` / `"50-"` → 从第 50 行开始
- `"50-200"` → 第 50-200 行（含首尾）
- `"50+150"` → 从第 50 行起 150 行
- `"5-16,960-973"` → 多段范围
- `"raw"` → 原样输出，不加行号和锚点
- `"2-4:raw"` → 范围 + 原样

## 截断行为

全量读取路径下，超过 100KB 字符上限时截断，并追加明确提示：
`--- 文件较大 (N)，仅显示前 100.0KB ---` + `--- 传 raw=true 读取完整内容，或用 :行号 选择范围 ---`
截断处内容**未读**，需要时用 `raw=true` 或 `:行号` 补读，不要脑补。

## 关键规则

- 绝对不要用 `ls` 或 `find` 列举文件 → `ls` 用 read 读目录（如 `path: "dir/"`），`find` 用 glob 工具
- 独立读取应并行执行
- 路径中有冒号时，用选择器语法（`path:行号`）而不把选择器拼在路径里
