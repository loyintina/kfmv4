# kfm-logs — 日志读取

读取 kfmv4 日志卡的内容。


<!-- gen:tool-params:start -->

## 参数

- `cardId`（可选）— 日志卡 ID，默认读取最新的日志卡
- `lines`（可选）— 读取行数，默认 100，最大 1000

<!-- gen:tool-params:end -->
## 使用时机

- 需要查看运行日志、调试输出
- 需要排查之前发生的错误
- 需要了解操作历史


## 输出

返回日志文本内容（读取 wsServer 最新快照中的日志元素，**非实时订阅流**，每次调用即当前状态）。

## 关键规则

- 如果日志量大，先限制行数再逐步扩展
- 日志是诊断工具，不是调试器的替代品
- 日志卡未渲染或为空 → `没有找到日志卡…` / `日志卡 "X" 没有内容或不存在`
- 遇到错误时优先查日志，再推测根因
