# edit — 文件编辑

在文件中查找指定文本并替换为新文本。精确到首次匹配。

## 参数

- `path`（必填）— 要编辑的文件路径
- `old`（必填）— 要替换的原文本
- `new`（必填）— 替换后的新文本

## 使用规则

- 必须先用 read 读取文件至少一次，才能编辑
- 用最小的 `old` 字符串唯一标识替换位置
- 如果 `old` 不唯一，增加更多上下文使其唯一
- 修改已有文件优先用 edit，不要用 write 覆盖整个文件

## 输出

- 成功：`编辑成功 (替换了 1 处)`
- 失败：`未找到匹配文本: "xxx..."`

## 效率提示

- 用 `git show` 看原代码，搬过来后只改需要改的
- 禁止凭记忆重写——用 `read` 确认实际内容
