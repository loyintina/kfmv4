# kfm-compact — 压缩当前会话的上下文

把远期对话蒸馏成结构化摘要（deepseek-v4-flash），固化进会话文件的 `compacts`
数组——**真相源 messages 一字不动**（宪法第四条：投影压缩，真相源留存）。

**触发即生效于下一轮**：固化后 cutIndex 前移，下轮请求投影自动跳过远期，
载荷立即下降（三数字的 a 变小）。AI 可自主调用——90% 自动压缩失败时的
兜底、完成大任务后主动瘦身、会话卡 token 数字过大时。

## 参数

- `reason`（可选）— 压缩原因（记录用，如「上下文接近上限」「任务完成瘦身」）

## 行为细节

- 压缩保留最近 12 个完整用户回合（8 轮全保 + 4 轮纯对话）——摘要覆盖之外的
  近期工作手感不动
- 摘要滚动蒸馏：旧摘要 + 新增对话 → 新摘要（不重复覆盖）
- 返回压缩交接：cutIndex / 摘要长度 / 真相源总数 / 载荷变化（before → after）
- 会话文件：`~/.kfmv4/sessions/<id>.json` 的 `compacts` 数组（可 read 回读全文）

## 使用时机

- 上下文接近窗口上限（90% 自动压缩兜底）
- 完成一个大任务后主动瘦身（长会话的 token 账单明显下降）
- 会话卡 a 数字（实际请求载荷）过大时
