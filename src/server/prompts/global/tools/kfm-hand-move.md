# kfm-hand-move — 移动 AI 的手到指定坐标

把「AI 的手」（紫色意志核 + 卫星）移动到浏览器视口的指定坐标。手会以
弹性物理动画移动到目标（卫星自然跟随），停留 1.5 秒后自动回归待机轨道
（利萨如巡逻）。

**坐标基准**：浏览器视口绝对像素，原点左上 (0,0)，右下 = 视口宽高。
可用眼睛文件（eyes.md）的「标定坐标系」或各面板 coords 获取真实坐标。

## 参数

- `x`（必填）— 目标 x 坐标（视口绝对像素，0 = 最左）
- `y`（必填）— 目标 y 坐标（视口绝对像素，0 = 最顶）

## 行为细节

- 服务端用最新浏览器快照的 viewport 校验坐标：**超出视口直接报错**（不执行）
- 无浏览器连接（无快照）时拒绝执行
- 坐标合法 → ws 广播 `hand-move` → 客户端核弹性移动到目标，1.5s 后回归待机轨道
- 移动动画是弹簧物理（加速到位 + 轻微过冲回弹），不是瞬移——AI 动作与
  用户所见一致（「手可见 → 动作可信」）

## 使用时机

- AI 需要"指向"页面上某处（配合眼睛文件坐标，让用户看到手落点）
- 验证眼睛坐标与实际 DOM 位置的一致性（手落点对照）
- 后续动作链（点击/拖拽）的基础——手先到目标，再按下
