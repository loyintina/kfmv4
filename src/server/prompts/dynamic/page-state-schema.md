# page-state.md 格式说明（眼睛动态文件）

> 本文档描述**动态提示词文件** `page-state.md` 的内容形态——里面可能出现
> 哪些文本、具体格式、什么情况下出现。AI（或人）挂载该动态文件前先读本文档。
> 文件本体由程序生成（`src/server/ai/page-state.ts`），**不要手动编辑**；
> 若代码改动格式，本文档同步维护。

## 是什么

「眼睛」——kfmv4 面板浏览器页面的实时状态投影，MUD/文字冒险风格的「房间描述」。
它回答 AI 三个问题：你在哪 / 你能看到什么 / 你能做什么。整个文件是纯 Markdown，
只有段落标题、列表项和行内标记，没有嵌套结构。

## 位置与刷新时机

- 位置：`.kfmv4/prompts/dynamic/page-state.md`（数据目录，程序生成；
  与源码 `src/server/prompts/dynamic/`（说明文档）路径对称）。
- 刷新：每次工具调用后由 `refreshPageState()` 重写（读浏览器推上来的页面
  快照渲染）。AI 每轮 LLM 调用前 `assembleDynamicPrompt` 重读 → 注入对话尾部。
- 不出现：角色卡没在 `dynamicPromptFiles` 里列它 → 完全不注入（零影响）。

## 完整结构（正常有快照时）

整个文件固定由以下行构成（空行位置也固定）：

```
# 当前页面状态

> 本节由系统在每次工具调用后自动刷新，反映你的操作对页面的实际影响。

## 你能看到什么
（内容层，0 或多条列表项）

## 当前页面元素
（交互层，0 或多条列表项）

## 你能做什么
（能力层，0 或多条列表项）
```

「你能做什么」段之后没有结尾空行，文件到此结束。

## 各段可能出现的一切文本形态

### 头部（固定两行，不变）

```
# 当前页面状态

> 本节由系统在每次工具调用后自动刷新，反映你的操作对页面的实际影响。
```

这两行是常量，任何有快照的状态下都一字不差。

### 「## 你能看到什么」——内容层

内容层是**页面当前展示的信息摘要**，每条一行，形态：

```
- **<类型标识>**：<摘要文本>
```

类型标识 `<类型标识>` 来自浏览器快照的内容条目，当前可能出现的取值：

- `text-output`——页面最后一条输出消息。摘要示例：
  `最后一条消息: AI说「接手探索完成。按 onboarding 流程，向你复述我对 /root/kfmv…」`
  （长文本会截断，省略号结尾）
- `card-content`——卡片堆当前焦点卡。摘要示例：`卡片堆: [3/8] tmux`
  （格式：`卡片堆: [当前序号/总数] 卡片标题`）
- `file-tree`——文件树展开状态。摘要示例：
  `根目录: /root | 展开: /root/kfmv4, /root/.kfmv4/sessions, … +5项`
  （格式：`根目录: <路径> | 展开: <路径列表>，超过展示上限以 +N项 结尾`）

除了以上三种，**其他类型标识按快照原样透出**——将来客户端新增内容类型，
这里会出现新标识，格式仍为 `- **<类型>**：<摘要>`。

摘要为空时显示占位：

```
- **text-output**：(无摘要)
```

内容层一条都没有时（页面无可读内容摘要），整段只有占位行：

```
## 你能看到什么
（页面暂无可读内容摘要）
```

### 「## 当前页面元素」——交互层

交互层是**页面当前所有可交互元素**，每个元素一条列表项，完整形态：

```
- **<标签>**（<类型>） [<状态>] （禁用） — 操作后：<效果文本>
```

各组成部分**都可能缺席**，实际出现的形态是以下片段的组合：

- 标签：`**<标签>**`，用双星号包住。有标签用标签，没标签就用元素 id。
  示例：`**侧栏开关**`、`**光球**`、`**AI 输入栏**`
- 类型：`（<类型>）`，跟在标签后，括号包裹。可能取值（来自快照）：
  `button`、`text-input`、`panel`、`icon`、`floating-button`，以及客户端
  新增的其他元素类型。示例：`（button）`、`（floating-button）`
- 状态：` [<状态>]`，带前导空格 + 中括号。**只有元素有 state 字段才出现**。
  当前可能取值：`[closed]`、`[hidden]`、`[active]`、`[collapsed]`、`[expanded]`，
  其他状态值按快照原样透出。示例：` [closed]`、` [collapsed]`
- 禁用标记：`（禁用）`，**只有元素 enabled 为 false 才出现**。
- 效果文本：` — 操作后：<效果文本>`，**只有元素有 effect 字段才出现**。
  示例：` — 操作后：点击切换侧栏打开/关闭状态`、` — 操作后：打开后显示文件树`

因此元素行实际可能出现的最小形态到完整形态：

```
- **侧栏开关**（button） [closed] — 操作后：点击切换侧栏打开/关闭状态
- **光球**（floating-button） [collapsed]     （无 effect 时）
- **显示隐藏文件**（button） [active] （禁用） （禁用且有效果时效果跟在最后）
- **未命名元素**（button） [hidden]            （无 label 时用 id 占标签位）
- **输入栏**（text-input）                     （无 state、无 effect、无禁用）
```

注意顺序固定：标签 → 类型 → 状态 → 禁用 → 效果，缺席的片段直接跳过，
不补占位符号。

交互层一条都没有时（页面暂无可交互元素），整段只有占位行：

```
## 当前页面元素
（页面暂无可交互元素）
```

### 「## 你能做什么」——能力层

能力层是**当前对 AI 开放的可调用能力**，每个能力一条列表项，两种形态：

无参数：

```
- `open-sidebar` — 打开侧栏
```

有参数（参数列在名字后，括号内，`名字:类型` 逗号分隔）：

```
- `select-file`（path:string, focus:boolean） — 选择文件并聚焦
```

当前没有能力时（最常见），整段只有占位行：

```
## 你能做什么
（当前无额外可调用能力）
```

## 整体占位（无快照时）

浏览器未连接或未推送状态时（如服务刚启动、无面板打开），整个文件退化为
两行，**没有三段式**：

```
# 当前页面状态

> 暂无页面快照（浏览器未连接或未推送状态）。
```

写占位是为了避免旧内容误导 AI——宁可说没有，不可拿过期状态当现状。

## 内容随什么变化

- 用户在浏览器里操作（开侧栏、展开文件树、点卡片）→ 元素 state 变化、
  file-tree 展开列表变化、卡片堆焦点变化
- AI 自己发远程命令（open-sidebar / select-file / click-path 等）→
  操作的效果写回对应元素的 state 与 effect
- 聊天进行 → text-output 变成最后一条消息

## 使用注意（与 evidence-discipline 呼应）

1. 投影可能滞后或不完整——它是页面快照的渲染，**不是证据源**；
2. 涉及文件内容/状态/计数的断言，**以工具读取的实际结果为准**；
3. 感官与工具结果冲突时，以工具结果为准（注入 wrap 已声明）；
4. 不要主动提及「我看到/眼睛察觉到」——信息直接取用（wrap 使用规则）。
