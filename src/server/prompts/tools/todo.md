# todo — 任务列表

管理当前会话的任务追踪。

## 操作类型

| `op` | 参数 | 效果 |
|------|------|------|
| `init` | `items: string[]` | 初始化任务列表（替换已有） |
| `start` | `task` | 标记为进行中 |
| `done` | `task` | 标记为已完成 |
| `drop` | `task` | 标记为放弃 |
| `rm` | `task`（可选） | 删除指定任务；省略则清空列表 |
| `append` | `items: string[]` | 追加新任务 |
| `view` | — | 查看当前列表 |

## 任务内容规范

- 5-10 字，描述做什么，不描述怎么做
- 唯一标识符，不要用 `"task-1"` 这种自创 ID
- 完成立即标记 done

## 何时创建列表

- 任务需要 3 步以上
- 用户明确要求
- 用户提供了任务集合
- 中途收到新指令 — 先记录再执行
