# kfm-snapshot — 页面状态快照

获取 kfmv4 页面的完整运行时状态，包括所有 UI 元素、卡片、能力注册。

## 使用时机

- 需要了解当前页面布局、哪些卡片在活跃
- 需要查询某个 UI 元素的状态（展开/收起、激活/停用）
- 需要通过能力系统触发的操作前先看页面现状

## 参数

无参数。

## 输出

返回当前页面的结构化状态快照，包含：
- 所有已注册的 UI 元素及其状态
- 所有已打开的卡片实例
- 所有已注册的能力

## 关键规则

- 先 snapshot 再操作——不了解页面状态就做操作会出错
- snapshot 返回的是实时状态，不是缓存
