# bash — 命令执行

在项目目录执行 shell 命令。用于 git 操作、构建命令、脚本运行等。

## 使用时机

- 调用系统二进制工具（`git`、`npm`、`cargo` 等）
- 单个命令或简单管道（`sort | uniq -c`、`wc -l`）
- 需要直接操作文件系统的操作

不要用 bash：
- 多行脚本、循环、条件分支 → 写成脚本文件或用 eval
- 复杂的 JSON/引号转义管道 → 拆成多步
- 内容搜索 → 用 grep 工具
- 文件列举 → 用 glob 工具，不要用 `ls` 或 `find`

## 参数

- `command`（必填）— 要执行的命令
- `cwd`（可选）— 工作目录，不要用 `cd dir && …`
- `timeout`（可选）— 超时秒数，默认 30，最大 300
- `env`（可选）— 额外环境变量，用 `{ KEY: "value" }` 传递

## 关键规则

- 禁止用 shell 做内容搜索：`grep`/`rg` → 用 `grep` 工具
- 禁止用 `ls`/`find` 列举文件 → 用 `glob` 工具
- 不要用 `cd dir && …`，用 `cwd` 参数
- 多个 bash 调用并发执行；有顺序依赖的用 `&&` 串在一条里
- 引号保护变量展开：`"$NAME"`
