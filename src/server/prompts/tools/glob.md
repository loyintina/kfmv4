# glob — 文件查找

通过通配符模式快速匹配文件和目录。

## 参数

- `pattern`（可选）— glob 模式（如 `"*.ts"`、`"src/**/*.ts"`），默认 `"*"`
- `path`（可选）— 搜索目录，默认项目根
- `hidden`（可选）— 是否包含隐藏文件，默认 false
- `maxResults`（可选）— 最大结果数，默认 200

## 关键规则

- 多个目标用分号分隔：`"src/**/*.ts;test/**/*.ts"`
- 禁止用 `ls` 或 `find` → 全部用 glob 工具
- 需要多轮查找？用 Task 工具分发子任务
- 目录结果以 `/` 后缀标识
