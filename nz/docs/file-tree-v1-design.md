## 一、范围

**做**：文件树卡片（只读）+ AI 聊天输入栏 `@` 文件引用 + 服务端文件索引/读取 API。
**不做（v1 明确排除）**：文件增删改/移动（v2）、拖拽、Obsidian 集成、
拼音搜索（v2）、字符雨（用户裁决：文字随容器展开揭示替代）。

## 二、服务端 API（三端点，fail-closed）

### 2.1 排除规则（单一来源，三端点共用）

```
默认排除：.obsidian/ .smart-env/ .trash/ node_modules/ .git/
        隐藏文件（.开头）与隐藏目录
配置：NZ_FS_ROOTS（冒号分隔允许根，默认=HOME）；
     NZ_FS_EXCLUDE（追加条目）
策略：路径规范化后必须落在允许根内，越界一律 404（不透露存在性）；
     符号链接不跟随（防逃逸）。
```

### 2.2 端点

| 端点 | 方法 | 入参 | 出参 | 说明 |
|---|---|---|---|---|
| `/api/fs/list` | GET | `?dir=相对路径` | `{dir, entries:[{name,type:'dir'\|'file',size,mtime}]}` | **懒加载**：只返回直接子层；排除规则过滤后返回 |
| `/api/fs/index` | GET | 无 | `{roots:[…], files:[相对路径…], builtAt}` | 全量相对路径索引（@ 引用模糊搜索用）；9.4K 条约 300KB，gzip 后 ~80KB，一次性拉取 |
| `/api/fs/read` | GET | `?path=相对路径&max=字节` | `{path, truncated, text}` | 文本预览（默认 64KB 截断）；二进制探测（NUL 探测）返回 `{binary:true}` |

索引刷新：进程内缓存 + mtime 失效（任一允许根的 mtime 变化即重建）；v1 不做 fs.watch。

## 三、文件树卡片（UI 规格）

### 3.1 令牌表（na 照抄即同手感）

```ts
// 缩进：递减表，深层钳 2px（防深层目录出屏）
const SHIFT_TABLE = [18,16,14,12,10,9,8,7,6,5,4,3,3,2,2,2,2,2,2,2]; // index=深度
const shift = (d:number) => SHIFT_TABLE[Math.min(d, SHIFT_TABLE.length-1)];

// 逐层加深（嵌套叠加出纵深；深层更浓不是更淡）
const density   = 1 - shift(d) / 18;                 // 浅≈0 → 深→0.89
const topAlpha  = 0.02 + density * 0.18;             // 容器渐变顶
const botAlpha  = 0.08 + density * 0.35;             // 容器渐变底
const borderOp  = 0.3  + density * 0.5;              // 左强调边框
// 左强调边框：2px 圆角4，色 nz tokens --kfm-accent 系

// 行规格
行高 26px；字体 11px system-ui；超长省略号截断（CJK 按宽断行）
目录/文件色：ink-1 / ink-2（nz tokens）；选中底：accent 15%
容器投影：filter blur(12) 偏移(-4,0)——每层像向左错开的卡片
展开三角：9px，展开旋转 90°，transition 180ms
```

### 3.2 结构与状态机

```
FileTreeCard
 ├─ 状态：expandedSet:Set<dirPath>, loadedDirs:Set<dirPath>,
 │        rows:[{path,depth,type}], selected:path|null
 ├─ 懒加载：展开目录时 fetch /api/fs/list；结果并入 rows（该目录子层插入其后）
 ├─ 虚拟化：行高恒 26px → 窗口化只渲染可视区 ±屏高（自算，不引库）
 └─ 动画锁：展开/收起动画期间忽略新的展开点击（180ms 短锁，无 3s 队列——
    DOM+CSS transition 无竞态面，锁只防视觉抖动）
```

交互：点目录=展开/收起；点文件=预览（/api/fs/read → 预览浮层，v1 文本）；
长按=预留操作位（v1.1 清屏/重命名式操作抽屉，kfmv4 长按抽屉范式）。

### 3.3 动效参数表（动效判据：动效是解释，不是装饰）

| 动效 | 参数 | 解释什么 |
|---|---|---|
| 卡片入场 | 抽屉曲线 `cubic-bezier(.34,1.56,.64,1)` 320ms | kfmv4 全客户端弹性签名 |
| 目录展开 | 容器高度 0→auto（grid-template-rows 0fr→1fr）**240ms** 同曲线；子行 `overflow` 裁切被容器带出 | **字符雨替代**：文字被展开动作本身揭示 |
| 子行 stagger | 首屏子行依次 `translateY(8px)→0 + opacity 0→1`，**每行错开 20ms，上限 12 行** | 结构从属关系（解释谁是谁的孩子） |
| 目录收起 | 高度 1fr→0fr **180ms**（出场比入场快 25%） | 出场不抢戏 |
| 三角旋转 | 90°，180ms | 状态指示 |
| 选中 | 背景 120ms fade | 反馈 |
| prefers-reduced-motion | 全部瞬移 | 无障碍 |

（字符雨彩蛋：v1.1 可选 DOM 版、≤60 字符、仅 ≤50 子项目录——用户点头才做。）

## 四、@ 文件引用（输入栏）

### 4.1 触发与流程

```
输入栏键入 '@' → 弹浮层（输入栏上方，模糊聚焦入场 160ms——BeautifulUI
streaming-text 判据：新内容以模糊度入场）→ 首屏=最近/根目录文件列表
→ 继续键入=实时模糊过滤 → ↑↓选择 / 回车或点选确认 → 插入引用文本
`@<相对路径>` → Esc/失焦关闭
```

### 4.2 模糊引擎（纯函数，na 可直译）

```
匹配域：相对路径（含文件名）
规则（按优先级）：
  1. 子串命中：路径任一 / 分段（/ 切分）含查询串（大小写不敏感，
     CJK 按字面子串）→ 命中
  2. 子序列命中：查询字符按序出现在路径中（经典 fuzzy）→ 命中
评分：分段名精确命中(100) > 分段前缀(80) > 子串(60) > 子序列(40)；
     越靠路径末段加分（文件名权重>目录）；越短路径加分
上限：返回前 20 条
CJK：字面子串匹配 v1 已可用（中文路径逐字命中）；拼音 v2
```

### 4.3 插入格式

v1：插入文本 `@<相对路径>`（光标置于其后）。引用 chip 化（可点击预览）
v1.1。该文本对 AI 的语义（读取文件内容作为上下文）属 AI 线，v1 只做引用插入。

## 六、红线

- 越界 fail-closed 不透露存在性；排除清单先行（.smart-env 596 文件不得污染）
- 主线程无阻塞网络（L0 纪律）；动画期间主数据零改动（kfmv4 双树原则的 React 表达）
- 虚拟化不引第三方库（26px 恒高自算）；不引模糊搜索库（引擎自写，na 直译）
- 壳/APK 零改动（纯网页件）

## 七、实施注记（2026-09-11 Phase 2 落地定案；与正文冲突处以本节为准）

1. **入口机制**：树页入口= @ 弹窗首屏「» 浏览完整文件树…」行 →
   `kfm-nz-fstree-open` window 事件（跨插件路由走 CustomEvent 词汇，
   kfm-nz-pool-open 同款）。v1 不绑左滑手势（PageSwipe:500 已归
   config-pool，两插件同层抢裁决=竞态面）；右滑返回 v1.1 再议。
2. **层级**：树页 z44 与池页同档（互斥态，两页并开时 DOM 后位者在上）；
   `data-kfm-fstree-open` 挂 documentElement → tokens.css 藏 tmux 控件+
   composer/光球升 45 恒顶（池页同款机关）——@ 弹窗与「插入 @引用」回流
   都要求 composer 恒可见可点。树页底=composer 顶（借
   `--kfm-aichat-composer-h` 实测单源）。
3. **平面行虚拟化 vs 容器动画的实施翻译**（§3.2/§3.3 偏差声明）：
   容器渐变/左强调边按行携带（同深度行共享色带+兄弟首尾 4px 圆角近似
   容器块）；容器级 0fr→1fr 高度动画由**行级 stagger 揭示替代**（观感
   等价：文字被展开动作揭示；类只挂展开后 600ms 短窗，滚动补挂不重播）；
   容器投影 blur(12) 随平面化退役；收起=瞬时（无出场动画）。B 档
   「虚拟化窗口」钉优先级高于容器动画复刻——9.4K 库滚动流畅是 C 档硬判据。
   缩进=递减增量表**逐层累加**（SHIFT_TABLE[i] 求和，总量钳 160px）。
4. **引用回流**：树预览浮层「插入 @引用」/ 弹窗确认 → 统一插入文本
   `@<相对路径>`（光标置后）；跨插件回流走 `kfm-nz-aichat-insert` 事件
   （composer PromptBar 消费，DOM 值为真源）。
5. **@ 触发词法**：`(?:^|\s)@([^\s@]*)$`（对光标前文）——@ 须词首；
   query 含空白即断词关弹窗（文件名含空格的极端场景 v1 不支援）。
   **弹窗开着时 Enter/Tab=确认选中**（§4.1 语义，优先于拍板⑭——拍板⑭
   管发送语义：弹窗关闭时 Enter=换行不发送，考卷⑩回归钉）。Esc/点外关
   （拍板⑬ 同款 document 捕获 passive 监听，那一指动作同时生效）。
6. **客户端缓存单点**（src/client/fs/api.ts）：全量索引+目录列表都在
   客户端会话级缓存（promise 记账，失败逐出重试）——「一目录一次网络」
   由缓存层担保、**跨消费者成立**（弹窗浏览档预热，树页展开零网络）；
   服务端 60s TTL 照旧。观测：fsStats()={indexFetches,listFetches}。
7. **结构纪律**（B 卷③钉实锤沉淀）：插件 mount 域闭包持机态（config-pool
   的 core 同款），hooks 一律不出组件函数体——mount 域调 useState/
   useRef/useEffect=Invalid hook call，插件整只缺席且 boot 链后续静默
   不跑（main.ts 挂载顺序靠后的代码全部不执行）。
8. **考卷**：B 档=tests/browser/file-tree.test.mjs 12 钉（跑前必须
   `npm run build`——考卷吃 public/bundle.js，不 build=考旧代码）。
   观测双源：页面侧 addInitScript 包 fetch 计数（独立于插件的网络真值）
   + __kfmNzFsTree()/__kfmNzFsAt() 插件记账钩子。
