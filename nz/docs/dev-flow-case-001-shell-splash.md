# 开发流程案例 001 · 壳层开屏（8.8.6）——第一个走完闭环的插件

> 2026-08-30 归档。定位：**9.0 第一个从需求到真机闭环的完整开发流程实录**。
> 不是功能文档（功能见 nz/TASK.md 8.8.6 条目），是流程经验——下一个插件
> 照这个骨架走。

## 流程七段（每段：产物 / 坑 / 纪律产出）

### ① 打样：demo 页 + 逐版真眼迭代
- 产物：`nz/public/splash-demo.html`（v1→v15），动画本体 `nz/public/splash-core.js`。
- 做法：用户每版真眼看效果提意见（菱形观感/环距/扫描线/亮波/色相），agent 改，
  **agent 自己也得能看见**——`?t=<ms>` 冻结帧 + 画布重画眼（cdp-device.mjs seq/cshot）
  让 agent 在后台逐帧验证「每帧画什么」。
- 纪律产出：**观感问题必须逐帧实录验证，DOM 状态断言≠画面**（「你确实能看到渲染
  过程吗」是对的质问）。

### ② 页面集成：考题先行
- 产物：splash 壳开机自播（预测缩放 introMs / complete() 收口 / 看门狗），
  考卷 `nz/scripts/splash-boot-verify.mjs`（6 断言，真机 CDP 两轮 6/6）。
- 坑：服务器缓存头 immutable 只算不用 → splash-core.js 被一年强缓存中毒，
  WebView 拿旧版永不更新（真机实锤 5ms 缓存命中）。
- 纪律产出：**考题先行**（先红后绿）；缓存头改了要验「真没缓存」不是「应该没有」。

### ③ 壳层移植：唯一真源
- 产物：MainActivity 双层 WebView（底终端/顶 splash），asset 开屏页，
  主题 windowBackground 盲窗帧。
- 做法：动画本体 splash-core.js **三处复用同一文件**（页面内开屏/demo/壳 asset），
  package.sh 打包时机械拷贝，不手抄不改写。
- 纪律产出：**唯一真源 + 机械拷贝**——同一行为多载体时，拷贝必须是构建期动作。

### ④ 观测基建：仪器居首
- 产物：`/__boot-marks` 端点（onCreate→splash-dismissed 八拍墙钟），
  `nz/scripts/boot-splash-capture.mjs`（冷启动全自治：杀→死透判→冷启→CDP 连拍）。
- 坑三连：decorView 自绘抓不到硬件加速 WebView（全黑，废弃）；裸 am start extras
  被 filterEquals 吸收（自杀令落空）；8026 在 App 死后变黑洞（fetch 无超时卡死）。
- 纪律产出：**判据外部化**（死透=CDP target 消失，不赌日志）；
  **先埋仪器再动手**（盲窗账是页面 performance 永远看不到的，壳自己记）。

### ⑤ 验收：数字账 + 像素实证 + 零回退 + 真眼
- 产物：三轮冷启动数字账（动画 0.15s / 可操作 2.7s / 退净 3.8s，稳定复现），
  f0 真机合成器像素（徽标实证非黑屏），五卷 44/44 + npm 90/90，用户真眼两轮回。
- 纪律产出：**真机数字收口**——「感觉差不多」不算账，同一判据跑三轮稳定才算。

### ⑥ 事故：卡开屏（最有价值的一段）
- 现象：用户「进入后只有启动画面不会进入了」。
- 定罪链：boot-marks 逐拍账发现矛盾 → CDP 直读页面内部态（first-frame 已发）→
  手动调桥开屏立摘（桥完好）→ 结论：隧道 flap 期 WebView 吃旧缓存 bundle
  （无桥调用版本）+ standard launchMode 多实例叠罗汉。
- 治本：壳层 15s 看门狗 + singleTask 单实例。
- 纪律产出（本案最重要的一条）：**任何「盖住等信号」的 UI 都必须有看门狗——
  信号链路上每一环（缓存/断网/桥丢）都可能缺席**。

### ⑦ 归档：改动即提交 + 通报入册
- TASK.md 逐条入账（含坑的定罪过程，不只记成功）；通报信两封落信箱
  （boot-report + incident-followup）；评审抽查权随时可行使（8026 attach 即活页）。

## 给下一个插件的流程模板

```
1. 打样：demo 页隔离迭代，agent 必须有「眼」（冻结帧/重画/遥测）才动手
2. 集成：先写红测（考题先行），唯一真源机械拷贝进载体
3. 观测：先埋仪器（marks/探针/端点），判据外部化
4. 验收：数字账三轮稳定 + 像素/逐帧实证 + 考卷零回退 + 用户真眼
5. 兜底：每条「等信号」路径都问一句——信号不来怎么办？（看门狗）
6. 归档：TASK 入账（含坑）+ 通报信落信箱 + 塞话评审
```

## 本案例产出的可复用工具

| 工具 | 用途 |
|---|---|
| `nz/scripts/boot-splash-capture.mjs` | 冷启动全自治取证（杀→判死→冷启→CDP 连拍真机像素） |
| `nz/scripts/splash-boot-verify.mjs` | 开机自播开屏考卷（6 断言） |
| `/__boot-marks` 端点 + 壳层八拍 | 「点击→页面出生」盲窗账（页面不可见段） |
| 画布重画眼 / `?t=` 冻结帧 | 动效逐帧后台验证（cdp-device.mjs seq/cshot） |
