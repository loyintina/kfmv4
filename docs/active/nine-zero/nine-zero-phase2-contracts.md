## 契约 0：机制三件套形式定义（2026-08-17 用户拍板定稿）

**定义**：机制 = 文档世界的插件单位 = **规约 + 机械执行 + 失效信号**，
三件套缺一不可。

- **规约**：书面规则，有固定出处（路径 + 锚点/编号），编号永不重排
  （API 稳定性承诺，与 constraints 纪律同源）；
- **机械执行**：不靠人记的执行体（脚本/检查/生成器/钩子/运行时守卫），
  或**显式标注"约定"**——承认此环节靠人，把税摆到明处（藏起来的约定
  最毒）；
- **失效信号**：它死了现实怎么叫（报红/构建中断/心跳停滞/误报回潮）。

**判定三问**（机制识别器）：

1. 有规约吗？——没有 = **野脚本**（不可审计）；
2. 靠人记吗？——是 = **约定件**（必须显式标注）；
3. 死了谁知道？——没人知道 = **薛定谔的机制**（禁止存在）。

**生命周期四态**（引用双终审定稿，此处形式化）：登记 → 巡逻 → 失效显形
→ 退役；退役内部实现 = 运行时卸载三相（嵌套：生命周期管"何时死"，三相管
"怎么死"）；退役判据 = 两种红（守护代码已删=正常退役删钉 / 回归红=事故）；
死后访问判红；broker 同名二次登记=报错。

**注册表条目扶正：五列 → 七字段**（`docs/active/mechanism-registry.md`）：

| 字段 | 来源 |
|------|------|
| 名称 / 分级（核心·外围）/ 机械化度 / 失效信号 / 探针 | 沿用现行五列 |
| **规约出处**（path#锚点） | 新增（补三件套缺口——现行 21 行无此列） |
| **状态**（四态之一） | 新增（为契约 2 broker 退役管理铺路） |

存量工作：21 条机制回填规约出处（一次性体力活，回填后机制第一次
三件套齐）。

**分级与升降级**：核心 = 失效必须立即显形；外围 = 接受滞后失效信号 +
用户抽查兜底。升降级通道：**外围→核心升级触发器 = 真实事故**（外围机制
失效造成一次实际事故即升核心补机械化——"使用中清晰"原则在机制层的
对应，不拍脑袋分级）。

**与运行时九字段模板的关系**：机制契约 = 运行时契约模板的**裁剪变体**——
砍掉 apply/unload 两栏（机制不装卸载，以生命周期四态替代）；字段映射：
provides=守护的不变量 / depends=依赖的数据源与机制 / 考题=探针夹具 /
状态归属=账本与注册表行。

**状态**：✅ 定稿（2026-08-17 用户拍板四条：判定三问+约定显式标注 /
七字段+存量回填 / 升级触发器=真实事故 / 裁剪变体关系）。

## 契约 1：降生协议（定稿）

**开题拍板（2026-08-17 用户拍板）**：

1. **协议形态 = A 降生链**：出生手续做成显式步骤清单（结构化文件，同工作流卡
   形态），CLAUDE.md 启动节由它**机械生成**（落实"发现面机械生成"硬要求）；
   每步带断言（如"降生完成时信箱归属行已读"），可机检——降生手续从约定件
   变机制（契约 0 三件套直接适用）；coldstart 考卷 = 它的探针；
2. **两种降生显式区分**：
   - **全新降生**——从未见过项目的 agent 接手，要的是地图（coldstart 考卷测此）；
   - **会话重生**——老 agent 压缩后继续，要的是交接（干到哪/状态/下一步；
     摘要质量 = 重生质量，继承面吸收 compact 教训）。

现状病灶记录（四方表态汇总）：跨线信箱不在任何启动路由（茉莉活 bug）/
启动手续是散文无断言（未显式标注的约定件）/ 出生与重生混为一谈。

已定硬要求清单（双终审，不再讨论）：发现机械生成 / 报错两分（"登记了
没点亮"vs"从未声明"）/ 注入分静态·动态两层 / 动态层时机=降生完成时 /
启动扫描信箱归属行 / 继承面吸收 compact 摘要教训。

**定稿（2026-08-17 用户拍板三条）**：

1. **步 0 身份定位**（新增，链一第 0 步）：我是谁 / 归哪条线 / 本会话任务——
   三者明确才进事件面接线（信箱归属行扫描的前提是知道自己归哪线）；
   不明确走"无归属"分支（通用待办照扫，自知无归属）。链二不加重生步，
   但继承面立第一条规矩：**摘要必须含身份**（压缩丢身份 = 重生变 orphan）；
2. **断言分两档**：结构类 → 真脚本机检两件套（① 生成一致性：CLAUDE.md
   启动节 == 降生链生成物，gen + `--check-only` 同路由表模式；② 接线完整性：
   链引用的每个文件存在 / 每个机制在注册表 / 每个信箱在链上——check-checks
   自指门的降生链版）；认知类（摘要是否蒸馏、地图真懂没懂）→ 不机检，
   归 coldstart 考卷——**契约 1 的探针 = 结构类检查器 + coldstart 认知考卷**；
3. **降生链文件 = `_birth.yaml`**（位于 `docs/workflows/` 下，实现期创建）：
   下划线前缀沿用 `_template.yaml` 的"特殊件"惯例；白拿 workflow-integrity
   现有巡逻；路由表生成器跳过它（出生不是任务路由）；实现期确认
   `_template.yaml` 的豁免方式并沿用。

**链一定稿（八步）**：0 身份定位 → 1 环境定位 → 2 进门三验 → 3 世界地图 →
4 状态注入 → 5 事件面接线（信箱归属行扫描）→ 6 约束注入 → 7 任务路由。
完成断言：八步全走完，动态内容此刻一次求值（非首次用到时）。

**链二定稿（四步）**：1 继承摘要（蒸馏非截取 + 含身份）→ 2 状态对账 →
3 事件面对账 → 4 手头重建。两链共享状态对账与事件面（世界状态对两种
降生相同），差别在"你是谁"：全新降生要地图，会话重生要交接。

**静态/动态分层**：链一 1/3/6 步 = 静态层（会话内恒定，吃前缀缓存）；
2/4/5 步 = 动态层（每次降生求值）；链二全动态。

**报错两分落实例**：信箱文件"存在但没接线"（补降生链）vs"从未声明"
（先建机制）——两种报错两种修法，写进步骤断言文案。

**状态**：✅ 定稿（2026-08-17）。

## 契约 2：机制注册表扶正 broker（2026-08-17 用户拍板定稿）

**诊断**：注册表自身是未机制化的机制——文件头自认"低频手工维护，无常驻
自动化"：靠人记（未标注的约定件）+ 无失效信号。扶正 = 注册表自己也过
契约 0 三件套。

**broker 定义** = 注册表文件 + 机械守卫 + 退役协议，**不新造实体**（对应
运行时 №6 的文档世界版）。

**机械守卫四件**（只守"现实锚点"，不守机制本身——递归终止原则的落实）：

1. **完备性**：scripts/ 每个 check/gen 脚本必须在注册表有行、或显式豁免
   （脚本文件是现实，机械可对账）；
2. **同名报错**：注册表两条同名机制 = 报红（NA"同名二次登记=报错"落点）；
3. **规约出处真实存在**：每行"规约出处"列的 path#锚点必须真实（文件系统
   是现实）；
4. **死后访问**：退役名单内的机制仍被文档/检查引用 = 报红。

**递归终止**：broker 整体停滞（没人维护了）**不设机械守卫**，失效信号 =
降生时发现 + 用户抽查（信箱同款待遇）。总有一层的死活靠人看，让它停在
最浅一层——这是递归终止原则的代价，拍板认下。

**豁免清单**：放注册表文件末尾的豁免区，与机制同文件，一眼对账。

**存量回填**：21 条机制逐条补"规约出处"与"状态"两列（契约 0 欠的体力活，
随扶正一次完成）。

**状态**：✅ 定稿（2026-08-17 用户拍板三条：守卫四件 / 递归终止处理 /
豁免区同文件）。

## 契约 3：信箱事件面（2026-08-17 用户拍板定稿）

**定位**：信箱 = 文档世界 ctx 的事件面。本契约给手工原型立形状规矩，
机械化重写留给未来（议题 7"通信插件 v1 不立项"立场延续）。

**四种流型**（用户提出，真实例对号）：同一 append-only 日志的四种读法，
分歧不在"信"在**收敛**——不造四个机制（议题 7"私聊群聊同一总线两种
视图"纪律）：

| 流型 | 寻址 | 完成判据 | 真实例 |
|------|------|----------|--------|
| 链条 1:1 | 致某线 | 回执闭环 | Cordis 采用：卡萝送审→评审裁决 |
| 征集 1:N | 致全线 | 发起人整合 + 终审 | 沙漏信四方表态（讨论区=收集器） |
| 汇总 N:1 | 致汇总者 | 汇总者出成品（前提=收齐） | 评审整合三方表态出裁决信 |
| 线程 N:N | 全局 | **只登记形状名，不立规矩**（反预设：无真实例，撞墙再补） | 尚无 |

**信封头部四字段**：致（寻址）/ 流型 / 预期表态方（征集与汇总必填 = 收齐
判据）/ 收敛判据（什么算这轮结束）。

**回执义务按流型定**（不再只按信件类型）：链条=必须回；征集=预期表态方
必须表态；汇总=汇总者欠一份成品；线程=待定。"多久算停滞"维持现状判据
（状态列长期不动=失效信号），不定死天数。

**事件/落盘分离**（卡萝，对齐 №10 ledger-service append-only，不发明第三种
形态）：信件文件 = 日志（一信一文件、只追加、永不改写）；README 状态列 =
从信件推导的**投影**。

**机械件**：归属行扫描器（扫状态列列出归属某线的待办）= 本契约第一机械件，
同时是降生链第 5 步的依赖；**代际戳**（NA 实例比对映射）：状态列更新带
更新者+日期，过期回执覆盖新状态对账判红。

**git 卫生升机制**（评审，议题 6 冲突面管理第一活标本）：commit 只 add 本线
文件清单，v0 = commit 前脚本化检查；该检查登记进机制注册表（契约 2 broker
接住）。

**订阅（push）缓建**：现状 pull（降生时主动扫）；真多 agent 集群再议。

**即刻手工纪律两条**（双终审已立，重申）：回信自更新状态列 / commit 只 add
自己线文件。

**状态**：✅ 定稿（2026-08-17 用户拍板：信封四字段 / 回执按流型 /
N:N 只登记形状名 / 归属行扫描器 / git 卫生 v0 / 停滞判据维持现状）。

## 契约 4：文档户籍机制（2026-08-17 用户拍板定稿）

**定位**：文档系统族第一契约（六族逐族契约开张）；文档世界的实体注册表
（对应运行时 №6 卡片注册表）；用户 2026-08-17 提议。管辖范围已拍板：
全项目机制可达文档，至少含实验区，法外之地显式豁免。

**入户最小三样**（不多要，字段税按存续时间收）：

1. **层级**——从路径机械推导（七层/实验区/根目录），不用人填；
2. **消费者**——至少一个读者（检查器消费 / 工作流引用 / 路由指向 /
  生成物收录）；一个都没有 = 孤儿（继承孤儿门老规矩）；
3. **户籍状态**——入籍 或 豁免（豁免必须写理由，同"约定件显式标注"纪律）。

"属主"与"生命周期"**不强制**——使用中没撞上需要的墙，撞墙再补
（反预设家风）。

**形态**：**单扫描器**单次遍历全项目，三分流判罚（入籍/豁免/报红）；
不做一族小检查器（普查一遍就够）。存量三胚胎（doc-orphans /
doc-coverage / doc-tree-sync）**不动**，绞杀者并立，新警接住活后再议合并。

**影子先行**（与安全包"影子转正"同节奏）：

- **v1 = 只丈量不执法**：产出户籍覆盖率（入籍+豁免÷全部文档），喂
  `docs-status.mjs` 仪表盘（本就非阻断）；
- **v2 = 增量执法**：豁免区登记完后，门只挡**新增**黑户；存量一笔勾销。

**原则注记**（2026-08-17 讨论）：**建造放开、采纳收紧**——AI 时代生成的
成本塌陷，但验证/理解/存续税没有；设计要完整细粒度，进核心区要证据。
户籍警影子先行 = 该原则首例。

**依赖关系**：降生链发现面读地图，户籍警保证地图完整（无黑户不在图上）。

**状态**：✅ 定稿（2026-08-17 用户拍板：最小三样 / 影子先行）。

## 契约 6：生成器族（族契约 · 轻量四件，2026-08-17 用户拍板定稿）

**归位确认**：物理定律的自动维持——"可生成事实单一出处"的机械化。

**三件套对账（基本健康）**：规约=单一来源纪律天然存在 / 机械=全量
