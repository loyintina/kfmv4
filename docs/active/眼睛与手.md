## 动态/常量标注约定（2026-08-10 立）
- 【动态】= 程序实时生成——坐标（实时量取）、内容（数据源路标）、状态（隐藏/展开/聚焦等）
- 【常量】= 设计定死——行格式、编号规则、状态枚举、窗口条数、面板字段结构
- 标注规则：坐标一律【动态·实时量取】；内容一律【动态·数据源】；格式/枚举/窗口标【常量】
- 例外处单独标注（如"对话窗口 3 条"是常量、"卡片清单=注册表枚举"是动态）

2.当前展开文件（#文件树全量真实记录——所有可见项，含折叠目录）
(1)行格式：【常量】`(编号)(层级缩进)(状态)(路径)<光标>`
(2)编号：【常量·规则】深度优先序，从 1 连续编号（**展开与折叠项都编号**），供 AI 引用操作
（如「展开(5)」「选择(8)」）；编号是当下快照的序号，文件树变化即刷新失效
(3)层级缩进：每层 2 空格，缩进表示父子关系
(4)状态枚举：【常量】
  - `展开`——目录已展开，其子项在后续行列出
  - `折叠（N）`——目录未展开，N = 该目录**直接子项数（含隐藏 . 开头项）**（子项不列出；如 /root 的 N 会把 .bashrc/.bun/.kfmv4 等点项计入）
  - `文件`——普通文件，无子项
(5)光标：`<光标>` 标记唯一当前项（光标所在行；全树至多一处）
(6)示例（/root 实况简化）：
{
(1)展开/root
(2)  折叠（5）/root/箱子
(3)  展开（4）/root/kfmv4
(4)    文件/root/kfmv4/package.json
(5)    折叠（20）/root/kfmv4/src
(6)  折叠（3）/root/kfmv4-lab
(7)  文件/root/reasonix.toml
(8)  文件/root/clash_config.yaml<光标>
(9)  折叠（2）/root/.kfmv4
}
说明：编号深度优先——(2)箱子 折叠则其子项不出现；(3)kfmv4 展开则
(4)(5) 是它的直接子项（缩进 2 空格）。(5)src 折叠（20）= src 下 20 个
直接子项未展开。
(7)生成来源：【动态】tree-model / state 的展开状态 + 光标位置 + 子项计数（getter 提供）

(一)最小动作工具集
分层架构（2026-08-10 定稿）：
- **物理层（ACTION）**：通用手势——工具调用链的**底层胶水**，语义动作最终
  落到物理动作执行（展开目录→点击该位置）。**全保留，不可删**。
- **语义层（TREE/ORB/CARD）**：按区域组织的意图动作——基于眼睛的编号/名称。
- **动作链层（(二)）**：最小动作的组合（意图→执行→组合三层）。
- 原则：**AI 动作 ≠ 人动作**——滚动用光标定位替代、弹窗确认走工具链、
  不复制人手势；物理层是执行基础不是复制人手。
