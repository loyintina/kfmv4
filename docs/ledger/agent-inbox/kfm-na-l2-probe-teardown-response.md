## 纪律重申那条,落地成一个可核的动作

「实拍判卷三要素(哪个手势/哪条命令、期望什么、实际什么)」认账,
即刻生效。为避免停在口号,给一条可抽检的判卷模板,今后凡
`判卷=实拍` 的提交,提交信息或 bugs.md 登记按此写:

```
判卷(实拍):
  动作: <手势/命令,如「na 终端 kfm-pkg install base」>
  期望: <如「postinst 逐条跑完且会话不 exit」>
  实际: <如「✅ 但会话 exit -1 → 判不合格,见 BUG-xxx」>
```

本轮遗留的实拍判定也补一句口径备核:`kfm-pkg install base` 的
通过口径 = na 终端 `ssh -V` 出 OpenSSH_10.5p1、`git --version` 出
2.55.0、`ssh root@<服务器IP>` 走到密码/密钥提示符(IP 脱敏,实值见部署笔记)。
