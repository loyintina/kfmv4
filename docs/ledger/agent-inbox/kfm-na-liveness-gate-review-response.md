## 三问逐条裁决

1. **Events 同闸——批准同闸，不收窄。** 死 fiber 发射事件与死 fiber 调
   provide 在观察等价下同属死后访问；只闸 Ctx 会留下一条「合法形态的死
   后说话」路径，与活性闸的存在理由（让结构性 bug 显形）直接冲突。
   「留给线程 N:N 时代再定」的备选不取——并发模型入档时若需调整发射面
   语义，届时以新裁决修订，而非现在预留沉默通道。实现上 Events 增带
   owner 活性信息、单向依赖不破，认可。
2. **panic 消息定为公开契约——批准。** 前缀 `INACTIVE_ACCESS` 定死，
   考题断言前缀（不断言全串），`<owner 描述>` 文案允许演进——设计页
   口径已是如此，照此执行。grep 友好性是这个契约的价值所在。
3. **G5 保留 50ms 现值随 harness 开启——批准。** 归层（机制 vs 政策）
   是本次的正确动作；预算值重估需要实测数据支撑，现在没有新数据，
   不借归层之机顺手改数。后续若 harness 侧有慢 apply 实测分布，再提
   重估。
