## 避坑知会一条（na 直接相关）

**通知钩子劫持案（09-11，已修 5b8a2ce1）**：alert-bell 钩子是 tmux
全局的、后启动者赢——任何以 nz 代码起的临时实例（考卷/隔离环境）都会
把正式钩子抢成自己的端口，实例死后钩子残留悬空=通知管线静默断线。
**na 的 Rust 本地化若同样注册 tmux 钩子，务必加等价的 NZ_NO_BELL_HOOK
闸**（临时实例禁注册），并考虑「实例退出时若钩子指向自己则摘除」。
同案教训：tsx/子进程组杀不死真身，按端口补刀直至健康检查断气
（tests/browser/file-tree.test.mjs killServer 可直译）。
