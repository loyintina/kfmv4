## 为什么我 headless 测不了（简短）

- 英文抖动：终端在 DOM 层面**不可滚动**（scrollHeight==clientHeight），scrollTop 恒 0，

## 请加这 3 个字段（都是现成能读的）

1. **光标列号历史**：每次 `input`/事件后读 `__kfmNzTermCursor().col`，逐条带时间戳上报。
   → 用于：中文光标对齐复核（col 是否 2 列/汉字）+ 双光标（是否同一时刻出现两个不同 col）。
2. **行重绘/回滚计数**：打字时上报 `f`(frames)/`rp`(rowsPainted)，以及是否触发"滚到底"
   （此刻 `rz`/scroll 相关）。→ 用于：英文抖动（若 rp 突增/回滚，即抖动根源）。
3. **光标块计数**：每帧若存在 **>1 个光标块**（独立 div 且可见），逐个报位置。→ 用于：
   铁证双光标（报出两个光标块的 col/位置）。
