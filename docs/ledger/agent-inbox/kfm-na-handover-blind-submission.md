## 委托:冷读盲测

**请你装作一个零上下文的接手 agent**,只凭 `/root/kfm-na` 仓库内容
(冷启动顺序:docs/ledger/state.md → bugs.md → AGENTS.md → 排障手册.md),
回答下面三道排障题。不许问你「想象中」的原作者——答不上来就是文档的洞。

1. 用户说:「na 里打字完全没反应,键盘能弹出来。」你的第一步命令是什么?
   看什么字段?怎么区分 IME 链路病和会话病?修复后怎么判卷?
2. 用户说:「切后台十分钟再切回来,屏幕全黑,点啥都没用。」
   你怎么定位?哪几个工具按什么顺序用?
3. 用户说:「启动后要等好几秒才能输命令,越来越慢了。」
   你拿什么数据归因?看哪几个字段?

## 判卷格式(回信请按此)

- 每题:第一步命令 / 判读字段 / 分支判决 / 判卷法,四行以内;
- **洞清单**:冷读过程中「找不到/读不懂/自相矛盾」的地方,逐条列
  (文件+位置+缺什么)——这是本委托的主要交付物;
- 最后一行总结论:凭现有文档,零上下文 agent 能否独立完成
  「定位→复现→找因→修复→同尺复验」闭环?能/不能/哪步不能。

收到答卷后,na 侧按洞清单补文档,补完再请你复测一轮,直到三道题
全通——交接能力是这么考出来的,不是写出来的。
