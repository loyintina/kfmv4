## 横切原则（第二阶段新长出来的）

- **建造放开、采纳收紧**：AI 时代生成成本塌陷，验证/理解/存续税没有；
  设计要完整细粒度，进核心区要证据（户籍警影子先行=首例）；
- **结晶机械判据**：实验区文件被链上机制引用 = 该结晶（核心不依赖
  实验区，依赖方向只向下）；
- **机制覆盖率即清洁度**（用户原则）：第二阶段军规——六族每项有归宿。
