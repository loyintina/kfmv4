## 一、采纳，而且它不只是「建议」——是 tmux 线的刚需

你提的时刻正好：用户刚拍板 tmux 线提速（8.8.3→8.8.4→8.8.5，通报信
kfmv4-9.0-tmux-priority-notice）。**手机上没有 Ctrl+B 前缀键，tmux 窗口
管理就是废的**——标签页可以切，但 tmux 自己的拆窗/翻页/复制模式全要前缀。
所以按键栏不是可选项，是 tmux 线「能用」判据的一部分。

## 二、尺寸/映射口径（按你要的两句）

**布局照 NA 定稿原样抄，两排七列**：

```
上排: [Esc] [Alt] [Home] [PgUp] [ ↑ ] [PgDn] [Shift]
下排: [Tab] [Ctrl] [End]  [ ← ] [ ↓ ] [  → ] [Enter]
```

理由不展开创新——NA 已经趟过布局（↑↓ 同列、←↓→ 下排 3/4/5 列右手惯用），
双线同布局对用户肌肉记忆也是资产。栏几何：贴可视区底（`bottom = 视口差`，
随软键盘上浮），键高按触达下限（两排合计 ≈ 终端 4 行高以内），列宽均分
容器宽——键栏是 UI 层，不占终端格子。

**映射口径照四条纪律抄**：

1. 修饰键一次性粘滞（Ctrl/Alt/Shift 点亮 → 下次落字读走清零）——kfmv4
   「Ctrl+字母联动不上」的病根就是没粘滞，nz 直接从 NA 抄答案；
2. `keymap` 独立纯逻辑模块（`nz/src/client/term/keymap.ts`），A 档考题：
   Ctrl+ASCII→控制字节、Alt+X=ESC x、方向键/End 吃 `app_cursor` 模式位
   （?1h 发 SS3 `ESC O A`，否则 CSI `ESC [ A`）、粘滞一次读走清零；
3. 栏随软键盘上浮（复用 8.8.2 已落地的 visualViewport 防抖管道）；
4. 键位序按 NA KEYS 表。

**核要加一个小暴露**：`app_cursor()`（读 rio-vt 的应用光标模式位）——
与上轮 `cursor_visible()` 同款小改，一行的量级。
