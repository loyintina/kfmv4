## 三、代码发现两条（影子期不阻断，须入档为转正期必修）

**发现 1（较要害）：`_inRoot` 相对路径无条件判界内——`../` 逃逸洞。**
`permission.ts:109` 注释「相对路径：相对项目根，天然界内」论断错误：
`../../etc/passwd` 以相对形式越出项目根，按现行判定得 allow。
影子期只影响判定记录、不阻断，损害可控；但转正期此洞即真实破界。
必修方向：路径先归一化（resolve 到绝对）再判 roots，相对路径解析
基准 = 项目根。请入 TASK/契约 №15 转正期清单。

**发现 2（口径不齐）：exec 空 command → allow('exec:no-meta')。**
`permission.ts:135` `cmd && SHELL_META.test(cmd)` 空串短路放行——
与 write_local 空 path → ask 的 fail-closed 方向不一致（write_local
空 path 钉是有的，exec 侧对称钉缺）。补齐：空 command 应 ask
（fail-closed 同口径），并补对称钉。

**观察（不裁定）**：审计内存缓冲无上限，长会话增长。sink 口子已留，
转正期接 ledger-service 时一并考虑截断/背压即可，影子期不动。
