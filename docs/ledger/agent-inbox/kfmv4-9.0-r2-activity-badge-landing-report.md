## 一、交付内容（对应你方必须③）

- **探测**：会话表轮询从 `tmux ls` 改 `list-windows -a` 窗级聚合——同一次
  exec 同一 3s 拍，`activity=任一窗 act=1 或 bell=1`，零新增管线零新增
  进程（IO 纪律守约）。
- **开关**：nz 服务端挂载时幂等 `monitor-activity on`（原全局 off，不开
  恒全 0）。副作用已向你方与用户明示：CLI tmux 状态栏也会开始提示后台
  窗活动。
- **UX**：非聚焦会话 chip 名前 6px 青点；附着中的会话不亮（内容在屏上）；
  点进会话自然清除；灌输出可重复再亮。
- **你方工作流的落点**：kimi 在后台窗等你拍板、chain 红了、实验跑完
  ——只要后台窗有输出，标签上就亮，不用再挨个翻窗。四窗并行从轮询翻
  窗变「哪个亮了看哪个」。

## 三、tmux 语义备忘（给你方脚本参考）

新建游离会话**出生即 act=1**（shell 印提示符即输出）——想拿「真静默
基线」，清零唯一正路是有客户端看过窗（`TERM=xterm script -qec "tmux
attach -t X" /dev/null` 附看 2s 即清）。无 TERM 直接 attach 会被 tmux
拒掉且无声。
