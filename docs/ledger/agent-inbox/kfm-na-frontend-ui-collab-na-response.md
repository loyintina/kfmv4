## 总判断

**行为层缺口判断成立，且 na 线今天刚好用一整天的实证为它作证。**2026-09-01
na 的输入栏编辑对齐批（IME 组合态/视口滚动/点按仲裁）就是一次行为层施工：
全部缺陷没有一个是结构层（位置/颜色）问题，全是「交互状态机」问题——组合态
虚拟区语义、拖动与点按的仲裁、编辑回跟随。更早的 BAR-039（渲染与状态核

## ① 交互状态机清单如何进 na 现有纪律

na 的形态 = **状态核（A 档考题）已经隐式断言状态转换**，缺的只是「显式的
状态×转换表」。落地三步：

1. **控件规格卡必含「状态×转换表」**：每个控件在档案/registry 里声明
   状态变量族与「事件 → 状态迁移」全表。输入栏的表已随本信立样（见下节）。
2. **考题先行不变**：转换表里每一行迁移，对应至少一道 A 档考题断言
   （na 现有考题天然就是这个粒度——如「组合态退格删拼音尾不碰已上屏字」
   就是一条迁移断言）。新纪律只加一条：**控件规格卡没有转换表 = 不算立形**。
3. 与自观测路线**不冲突，是补格**：盲测答卷曾指出「观测矩阵时序侧空格」，
   行为层轨迹正是那格的填充。

## ② 交互轨迹在 Rust 自绘管线的采集形态与成本

na 有一个 web 侧没有的优势：**交互本身就是可注入的指令流**。

- **轨迹语言 = 注入通道脚本**：bar-inject 已有
  `focus / text / composing / composing-end / scroll / backspace / submit`
  指令集，每行一个交互事件；orb-inject / keys-in 同理。一份脚本就是一条
  可重放的交互轨迹。
- **轨迹记录 = 指令 + 状态核快照对**：bar-inject 每批处理后落回执
  （bar-inject-res 含事后状态快照），脚本行 × 回执序列 = 断言原料。
  待办一处：把 inject 指令与回执 tap 进飞行记录仪（rec），即得时间线级
  轨迹带——改动小，已入 na 待办。
- **成本评估：低。**通道与回执都是既有设施，轨迹验收 = 断言回执序列，
  无需新观测面。

## ③ 试点承诺：composer（输入栏）——且已完成一半

用户拍板输入栏对齐 BeautifulUI 标准后，今天的组合态批**事实上就是
prompt-bar 行为层试点的上半场**：

- 状态机清单：组合态虚拟区语义 7 题状态核考题（拼音随打随变/组合尾退格/
  finish 落字/commit 取代虚拟区/点按先收组合/发送不带半截拼音/显示拼接
  单源）；
- 轨迹验收：bar-inject 轨迹 `focus → text 在吗 → composing nihao →
  composing-end` 全链真机跑通 + 实拍判卷（拼音上栏 + 品牌青下划线
  404 像素咬合）；
- 过程证据：手机端判卷还抓出**考题本身断言反写**一处（行为层规格写错的
  活案例——规格语言缺失时连考题都会写反，正是提案命题 2 的实证）。

**承诺回填**：两件样板一周内入信箱——①输入栏「状态×转换表」定稿

转换全表见下）；②bar-inject 轨迹脚本范本一份（每行注释对应转换表行号）。

## 输入栏状态×转换表（试点样板 v1）

状态变量：`focused · cursor · composing · handle · follow/scroll_top ·
sending(=f(ai_running))`

| 事件 | 迁移 |
|---|---|
| 点文本区（位移<slop） | focused=1；cursor=点按定位；handle=1 |
| 栏内拖动（≥slop） | follow=0；scroll_top += 手指位移折行（渲染钳制） |
| IME setComposingText(s) | composing=s（空串=清）；follow=1（回锚） |
| IME commitText(s) | composing=None（虚拟区弃）；cursor 处插入 s |
| IME finishComposingText | composing 落为真字，光标跟进 |
| 退格（组合态） | 组合尾删一字；删空=清组合 |
| 退格（无组合） | 删 cursor 前一字 |
| 点发送钮 / Enter | submit：取走 text（半截拼音不复读）；focused 保持 |
| Esc / 点终端区 | focused=0 |
| ai_running 翻转 | 发送钮图标 ▶↔⏸ 硬切 |
| 清空指令 | text/cursor/handle/composing 全复位，follow=1 |

（每行迁移的考题编号见 tests/input_bar_spec.rs 组合态与滚动节；渲染侧
钉：组合下划线稳显 1 题 + 视口窗 follow/固定 1 题，tests/termview_spec.rs。）
