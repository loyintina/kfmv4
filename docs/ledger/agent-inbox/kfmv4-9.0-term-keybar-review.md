## 一、缺口：nz 终端卡没有按键栏

- 8.x：有 `initAuxBar`（ESC/TAB/方向键带 ctrl/alt/ctrl-alt 序列）；
- NA：有专门 `keybar.rs`（按键栏）+ `keymap.rs`（映射），A 档纯逻辑带考题；
- **nz**：term 插件只有 keydown→字节转换，**没有按键栏**。这是终端卡的功能缺口（用户提的）。

## 二、建议 nz 照 NA 的纪律补（这是推荐的参考，不是硬性口径）

**布局（两排七列，`kfm-na/src/keybar.rs` 定稿）**：
```
上排: [Esc] [Alt] [Home] [PgUp] [ ↑ ] [PgDn] [Shift]
下排: [Tab] [Ctrl] [End]  [ ← ] [ ↓ ] [  → ] [Enter]
```
↑↓ 严格同列（第 5 列），←↓→ 在下排 3/4/5 列（右手惯用）；第 4 列空位作分隔。

**四条关键纪律（nz 该抄的）**：
1. **修饰键一次性粘滞**（Termux 同款）：Ctrl/Alt/Shift 点一下点亮，下一次 commitText/落字时读走清零——手机没法按住，避免 kfmv4 卡片键盘"Ctrl+字母联动不上"的病根。
2. **映射在 keymap，A 档纯逻辑有题**：Ctrl+ASCII→控制字节（Ctrl+C=\x03）、Alt+X=ESC x；**方向键/End 分普通与应用光标模式**（对端开 `?1h` 发 SS3 `ESC O A`，非 CSI `ESC [ A`）——keymap 需吃 `app_cursor` 参数（模式位只有事件循环知道）。
3. **按键栏位置跟软键盘上浮**（视高 - 键盘 inset - 行高），否则被弹起的键盘盖住。
4. 上排第七列 Shift、下排第七列 Enter；其余键按 NA KEYS 表来（有 Android 键码）。
