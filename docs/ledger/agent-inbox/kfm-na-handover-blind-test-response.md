## 一、三道题答卷（零上下文，只凭仓库）

### Q1：打字没反应，键盘能弹出
- **第一步**：`bash scripts/na-type.sh 'ls\r'`（注入对照，绕 IME 直注 PTY）→ 接 `bash scripts/na-text.sh` 读屏看有没有执行。
- **字段**：na-text 读屏 + `na-stats.sh` 的 `keys/keys_bytes`（注入后必须涨）+ trace `ime` 段 `commit` 计数。
- **分支**：注入有效（ls 被执行）= 病在 **IME 链路**（键弹得出=Java 皮在，但输入不达）→ commit 恒 0 = BAR-039（IME 绑错库/旧核心，先查 `loader-pick`）；注入无效 = 病在**闸门 keys-in 或会话** → trace `gate` 段。
- **判卷法**：注入复现就用**同一序列再注入**（na-type 'ls\r' → na-text + stats keys 涨）——「我觉得好了」不算数。

### Q2：切后台 10 分钟回，屏幕全黑、点啥没反应
- **第一批**：`bash scripts/na-ping.sh` 判四态。
- **分支**：`background`=看门狗休假非病（BAR-036 前台门控）；`stall beat_age=Nms`=事件循环真卡死 → `loop-stall.log` + `na-trace.sh` 看卡死前最后事件；`alive`=循环活着 → 病在渲染/内容。
- **alive 但屏黑**：`na-shot.sh` 拍图 vs `na-text.sh` 读屏对照——text 有内容 shot 全黑=**渲染路径病**；text 也空=**会话/泵病**（`na-stats.sh` 看 `pump_calls` 涨不涨）。
- **判卷法**：同批工具重跑对照（text vs shot vs stats 同复验）。

### Q3：启动后好几秒才能输命令，越来越慢
- **第一步**：`bash scripts/na-trace.sh` 看 `boot/conn` 段毫秒戳（BAR-020~023 已销：字体探测/同步直报/冷连接；新慢找新大头段）。
- **字段**：`na-stats.sh` 资源画像——`draw_avg_ms` 帧账、`cpu_jiffies` 连拍两次求差得 CPU 速率、`rss_kb` 内存水位。
- **判卷法**：同款 trace/stats 复验，`draw_avg_ms`/`rss_kb` 是否回落。

## 二、洞清单（冷读踩到的「找不到/读不懂/自相矛盾」）
