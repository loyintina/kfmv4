## 一、用户拍板：不要两区，要单区底锚定终端

用户明确表达（原文要点）：**不是「上方滚动区 + 下方单独一行固定输入行」的两区模型**；要的是**单个连续终端区域**，行为如下——

1. **最底永远 = 内容最新一行**：新内容到了从底部往上把旧的顶上屏幕（复用 8.8.3c 的滚动/跟底/输入回底逻辑）。
2. **输出跟在输入行下方**：回车回显命令行后，输出续在其下，整体往上滚；最底永远是最近一行。
3. **空屏也底锚定**：初始只有提示符时，提示符/光标停在**视口底行**，上方留白——看起来像「内容已充满屏幕」，**不是**一片空白从顶部开始。
4. **去掉独立固定输入行**：不再有单独一行被钉在底部（去除两区分割，也无须 alt_screen 两区切换）。

## 二、需 9.0 做

1. 回退 8.8.3d 两区分割 → **单一连续终端区**：滚动区即终端本体，输入行并入流，不再独立钉底（固定输入行元素退场）。
2. **底锚定**：默认跟底（新输出在底时跟随），输入回底（回车/按键先把视口送回光标处）；最底=最新。
3. **空屏底锚定**：视口内提示符/光标整屏底对齐（上方留白），非顶部起始。
4. 键盘/vv 占位整体上移沿用（?kbOff、底锚位随 vv），但属底锚定终端的自然行为，不再是「独立输入行」语义。
5. 两区相关产物处置：`fixed-input-row.test.mjs` 两区断言改写成**单区底锚定考卷**；`alt_screen()`（?1049h/?1049l 双模式）与独立 `__kfmNzTermInputRow` 语义按其是否仍被底锚定复用，由 9.0 判断后明示（不再需要就退役）。

## 三、验收（A 档换考卷）

- **A 单区底锚定**：① 内容超屏后**底行=最新行**（最底=最新）；② 输出续在输入下、整体上滚；③ **空屏提示符在底行**（底锚定）；④ 键盘占位整体上移不回退。
- **不回退**：scrollback（8.8.3c，跟底/回底/可滚/千行）+ keybar（8.8.3b）全绿。
- **B**：千行长输出上滚不卡、内存有界。
- **C**：真机实拍（底锚定视觉 + 上滑翻历史 + 键盘弹起整体上移）+ 数字收口。
