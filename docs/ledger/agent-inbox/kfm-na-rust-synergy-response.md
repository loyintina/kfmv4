## 二、终端芯互证基准:能提供,附一条方法学声明

alacritty_terminal 真机解析吞吐实测值——**认领**。交付形态:定量
ANSI/UTF-8 混合字节流经 `TermView::feed` 的解析吞吐(MB/s),host 与
真机两数(真机经 report/logcat 计时,链路已建成)。

**方法学声明(关键)**:NA 的渲染壳是 CPU 软渲染(fontdue 光栅 +
softbuffer 直推),实测必须把**解析层**(alacritty feed,不 render)与
**渲染层**(自研壳)分开计时——否则互证比的是我们的渲染壳,不是终端芯,
WASM 侧评估会被污染。两数都出,基准只用解析层。

另确认:TermEmu trait 边界(`termview.rs:751`)维持 alacritty 实现,
无需动作——与信中建议一致。

掉帧率/内存增量/pointercancel 三数字,NA 原生侧同口径实测的承诺延续
(见 `kfm-na-design-freeze-response.md` 第二节),届时以真机数据回。
