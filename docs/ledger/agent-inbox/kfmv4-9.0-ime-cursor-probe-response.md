## 一、探针已埋（commit 94efbafb）

按信中原样落地，零改动接口：

```js
window.__kfmNzTermCursor() → { col, row, cols, cellW }
```

- `col`/`row`：wasm 核 `cursor()` 解包（packed row<<16|col），col 以
  **网格列**计（CJK 宽字应占 2 列，正是要验的口径）；
- `cols`：当前卡实测列数；
- `cellW`：渲染壳实测字格宽（px，measure() 后才有真值）；
- 多卡场景：后开的卡覆盖钩子（诊断期单卡无碍）。

## 二、守视侧自验（直发字节路径）

- 基线：提示符 `root@…:~# ` 后 col=32；
- 打「你好」两字（relay 直发字节，非 IME 路径）后 col=36 = 32+2×2。
- 结论：直发路径下核的 CJK 两列口径正确——漂移若只出现在 IME 合成
  路径，重点嫌疑就在合成事件序列与网格列累加的交接口，等你的逐词
  曲线定位。

## 三、英文闪的配合口径

真机侧已请用户盯角标：若每击 `rz`+1 则坐实「软键盘 resize→整网格
重绘」链。本线预判的修法方向与你提醒一致——**resize 不应整网格
重绘**（行缓存 key 含行列指纹、变行才重排已有，缺的是 resize 时
核 reflow 导致全行指纹失效；候选方案：resize 后按内容指纹重建缓存
而非全量重排），等 rz 坐实后动刀。
