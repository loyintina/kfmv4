## 一、先验① 与实验台 APK 的关系：**并存**（附三条理由+一条防漂移备忘）

采纳评审倾向，拍板并存：

1. **语义纯净**：实验台壳带观测语义（`?nosplash&_tApk`、自动化注入、splash 实验件），日常壳要的是「开机即干净终端」；两者语义混装会互相牵制——实验台将来加任何实验逻辑都不该让日常壳背上。
2. **节奏解耦**：实验台壳跟着实验走（随便刷、随便坏），用户日常主力壳必须稳定优先，版本节奏独立。
3. **成本核算**：打包链全量复用（`nz/lab/device-agent/android` 纯 Java 壳工程拷贝改参），双份的是配置不是逻辑，维护成本≈两份 properties 文件。

**防漂移备忘**（登记不实施）：若日后壳层改动频繁导致两份工程漂移，再合并为单工程双 flavor；首版不做，避免过早抽象。

- applicationId：实验台 `dev.kfm.nz.agent`，kfm-v4 壳拟 **`dev.kfm.v4.shell`**，并存安装互不干扰。

## 二、先验② 端口普查：**notice 的「端口对」须修正为「三元组」——钉 8029(桥)/8030(客户端)/8031(控制)**

实测普查（`ss -tlnp`，2026-09-02）：

| 端口 | 占用 |
|---|---|
| 8021 | kfmv4 8.x 主线（`dist/server/index.js`） |
| 8022 / 8024 | sshd |
| 8023 | nz 终端服务器 |
| 8025 / 8026 / **8028** | **现有 cdp-relay 三口**（桥 / 客户端 / 控制——`nz/scripts/cdp-relay.ts` 单进程三监听） |
| 8027 | kalo overlay |

**关键修正**：relay 架构是三口不是一对（P1 落地时的拓扑：桥 8025 ← kalo -L、客户端 8026 服务器本机、控制 8028 ← kalo -L）。notice 候选 8028/8029 中 **8028 已被现 relay 控制口占用**。

**钉死**：kfm-v4 relay = **8029 桥 / 8030 客户端 / 8031 控制**。三口全空闲（ss 实测），与实验台 8025/8026/8028 记忆法对齐（整体 +4），8029 起三连号。落地=同脚本第二实例纯 env（`NZ_CDP_BRIDGE_PORT=8029 NZ_CDP_CLIENT_PORT=8030 NZ_CDP_CONTROL_PORT=8031`），零代码改动；手机侧 kalo 加 `-L 8029 -L 8031`（8030 服务器本机，不出内网）。三口全绑 loopback，与实验台同强度。

## 三、splash 表态：同意评审倾向——首版 windowBackground 静态徽标帧，不移植 splash

- 8.x 无 splash-core，移植动画=跨线搬运，时间预算不成比例；
- 静态帧（黑底+菱瞳徽标，取 `kfmv4-shell-icon-src.jpg` 同源）先保证「点开即有物」，这是 nz splash 立项时的第一课；
- 后续若 8.x 也要开机动画，按 nz splash-core 的插件模式在**页面侧**做，壳保持无脑。

## 四、技术备忘逐条 + 一条建议

1. JPG→PNG + mipmap 各密度 + adaptive icon（底黑+菱瞳前景）：照做，P1 打包链工具已验齐备。
2. URL 时间戳防强缓存：照做实验台同款（`?_tApk=<ts>`；`nosplash` 8.x 用不上）。
3. §五纪律全套照搬：确认（WebViewClient / 热更续命 / 看门狗 / KeepAliveService）。
4. **建议（追加）**：日常壳保留 `setWebContentsDebuggingEnabled(true)` + 第二 relay 实例接 8029/8031——**8.x 主线从第一版就有真机像素眼**。这是 nz 自观测战略线的直接延伸：splash 立项时「黑屏 2-3 秒无人能看」的教训不该在主线重演。成本≈一行代码 + 一个 env 实例；攻击面与实验台同强度（三口 loopback + 反隧道链路）。若评审否决此条，降级方案=调试开关编译期常量，日常壳默认关，出症时出诊断变体包。

## 五、验收判据草案（对齐 P1 五条风格）

1. APK 安装启动即达 8021 页面可交互（无地址栏、无 vv 布局抖动源）；
2. `kalo -L 8029 -L 8031` 后，服务器从 8030 attach 到 kfm-v4 页面成功，**首张 8.x 真机渲染截图落账**；
3. 热更续命+看门狗闭环：杀 server → supervisor 拉回 → 页面自动恢复不断会话；
4. adaptive icon 各密度渲染正确（真机截图）；
5. 与实验台 APK 并存安装、互不干扰（applicationId 隔离实测）。
