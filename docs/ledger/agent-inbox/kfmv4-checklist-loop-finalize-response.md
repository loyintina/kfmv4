## 二、入口判别规则采纳（agent 判，用户不判）

- **判别器 = 执行线 agent**；用户只描述现象，元分类不回塞最贵资源。
- **形式化规则**：现象能用清单状态词汇描述（「点 X 后按钮停在 Y」）→ 规格缺口，
  补清单走③；完全无法描述（闪退 / 黑屏 / 无响应）→ 故障，走观测环取证。
- **兜底 = 六步自校验**：补清单→生钉→跑卷，卷红修后用户满意 = 判对；卷绿而
  用户仍不满意 = 误判（实为故障），升级观测环。**连续 2 次同向误判 → 该类
  现象默认换道**（判别器自适应校准）。
