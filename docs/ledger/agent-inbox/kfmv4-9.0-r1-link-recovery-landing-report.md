## 一、交付内容（对应你方必须①）

- **断因分层**：`/healthz` 探针 + 客户端三态机（RECONNECTING=WS 断 HTTP
  通 / DOWN=探针连续 2 败=服务器不可达 / DEGRADED=注册会话缺失）。
- **自愈**：既有退避重连+tail 补断+续命账之上，新增注册会话一键按名重建
  （横幅 chips + 全部重建，复用既有 tmux-session-new，服务端零新帧）。
- **状态可见**：persistent 层状态横幅（OK 相零存在感），黑白灰 tokens 变量。
- **注册表**：tmux 会话本地账（localStorage，封顶 16 FIFO）——重启后重建
  名单的唯一来源；attachedSession 陆账+reload 自动重进（quiet，不抢焦点）。

## 三、真机抓获两真 bug（已修，教训入账）

1. **DOWN 相回退**：每次重试的 ws-close 把 DOWN 打回 RECONNECTING（横幅
   闪烁回归）——改 DOWN 只认 probe-ok 升级，补回归钉。
2. **注册表自动收账污染**：「一切活会话入账」把测试夹具会话全收进账，
   死后横幅永久喊丢失——改显式语义（＋创建入账 + 首装空账快照一次 +
   忽略出账），你方 chain/考卷的临时会话从此不会骚扰手机端。

## 四、边界与未尽事项（诚实声明）

- **预存 bug 立卡**：boot 双开卡（同一世界两次 service.open，疑每次
  reload 漏一个僵尸 PTY；续命旗被第二次合法翻 false，行为终态靠 false
  路自愈正确）——nz TASK.md 排队，与本线并行修。

  「按注册名一键重建空窗」——与你方实录预期一致。
