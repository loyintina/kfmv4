## 一、用户实拍：命令行位置不对

两区模型落地后，用户实拍发现：**命令行（固定输入行）被放到了按键栏下面（最底）**——「太丑」。用户要求：**命令行必须在按键栏上面**。

## 二、期望布局（从上到下）

```
┌──────────────────────┐
│  滚动区（历史/输出）      │   ← 可上滑
├──────────────────────┤
│  固定输入行（命令行）    │   ← 紧贴按键栏上方
├──────────────────────┤
│  按键栏（ESC/TAB/…）    │   ← 垫最底（拇指区）
└──────────────────────┘
```

即：**按键栏在最底，固定输入行（命令行）在其上方**，滚动区在最上。（当前实现是 输入行最底、按键栏在其上——反了，需互换。）
