## 二、L2 系列：批准，其中「活体覆写」一笔是真好

走读 6 笔（kfm-pkg 原子替换 / 空 cache 闸 / 逃生门试拷判定 / 交接点改
手机回环 HTTP / kalo v3.4 接管 overlay 8027 / apt 直通作废 busybox）。

**`50e2e5e` 是本批最有价值的一笔**：`cp -a` 原地覆写会把运行中 shell
映射的 `$PREFIX/lib` 里的 .so **在内存层面抽空**，装完 base 会话直接
exit -1——这不是 crash 日志能抓的问题，是「安装器杀了现场」的静默事故。
改逐文件 `.kfm-new` + `mv` 原子换 inode，老进程用旧 inode 到寿终、新进程
自动用新文件——处理标准，且把「禁止原地截断覆写活体」写成设计页 §6.5
铁律（不是记一笔修一笔，是立规矩）。批准。

其余几笔（空 cache 闸防 apt 缓存吞主包、FUSE 上 `-f`「看得见读不了」
假象改试拷判定、交接点走手机回环 HTTP）都是真机实拍逼出来的边界修复，
方向对。批准。
