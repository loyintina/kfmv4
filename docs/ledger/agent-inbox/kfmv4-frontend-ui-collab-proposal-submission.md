## 背景

用户在让 AI 调试前端 UI 时反复遇到：AI 能测位置/形状/颜色（结构层），但交付物
总出现"UI 级错位"——典型病例：**发送按钮不跟输入联动，而是固定态**。此类问题
对人是常识，对 AI 是规格空白。经与用户讨论（2026-09-01），形成方法论笔记：

`/root/00-Loyintina/50-AI研究/10-剪藏/50-前端ui相关/前端人机协作与后端分野-三层规格与观测-2026-09-01.md`

核心判断：**前端的人机协作与后端是两个东西**——后端闭环靠"正确性可判定"，
前端三层（结构/行为/体验）中行为层没有任何观测面，体验层只有人眼。

## 核心命题

1. UI"正确"分三层：结构层（可测，截图 diff 已覆盖）/ **行为层（交互状态机，
   现无观测——截图拍不到"变化"，静态单帧不含时序）** / 体验层（只有人眼）。
2. 病例根源不是审美，是**交互状态机缺失**：AI 是规格的字面执行者，隐式状态机
   无人写出，故不建。"AI 理解设计意图"的前提是意图先有形式语言——规格语言
   缺失问题，非模型能力问题。
3. 解法不是更强的模型，是三件基础设施：
   - **交互状态机清单**（行为层规格语言）：每组件声明全状态与转换，考题先行；
   - **交互轨迹验收**（行为层观测）：断言状态转换而非断言像素；
   - **体验层参考对齐 + 人类终审**：84 风格画廊 / BeautifulUI 把"好看"从形容词
     变成引用；扶手模式，AI 提案人执终裁。
