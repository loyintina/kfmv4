## 落地内容

nz 服务端第一次站立（8.8.1 首件，用户拍板「先让服务跑起来」，8023
隧道口子用户点名开）：

- **`nz/src/server/index.ts`**：
  - HTTP 静态服务（public/）——`resolveStatic` 越界防护：**原样拒 `..`
    显形 403**（normalize 会把逃逸静默收编成 public 内路径——安全但
    语义含糊，「分不清是逃逸还是没文件」；显形拒绝消除歧义。875
    fail-closed 教训第二次主动迁移）；
  - 服务端 cordis 根总线 `serverCtx` + hello 见证插件（客户端同款
    出生仪式，服务端 cordis 化与客户端同窗口兑现）；之后一切服务端
    插件（term-connection 家族/ws 桥/agent-service）挂这棵总线。
- **端口口径**：8022 = v8 生产，8023 = nz，并存互不打扰，9.0 收口
  归位。python 占位静态服务（8-20 起）已替换。
- **绑定**（评审代改 commit 95ee8a04，本线收编）：默认绑 127.0.0.1
  （访问通道 = kalo 隧道 -L 8023），`NZ_HOST=0.0.0.0` 显式可选——
  显式选择可达性，不默认可达。教训入档：日志声称的语义必须与代码
  实际一致（裸绑 `*` 时 slog 声称 127.0.0.1 = 承诺错了）。
- tsconfig +@types/node：nz 不再是纯客户端工程。
