## 登记规程

1. 探针/审计发现归不进既有变体 → 挂核心码或 SEM900，进暂挂池（记于裁决流 keptFindings）；
2. 复发 ≥2 次 → 提案 `SEMxxx-Y`（Y = 递增序号）→ 裁决流确认（语义审计裁决流）；
3. 确认后登记本表：变体码 / 核心码 / 具现形态描述 / first-seen commit / 判例引用（同构案例）；
4. 同变体计数 ≥3 → 结晶回路提案机械化规则（进确定区）。
