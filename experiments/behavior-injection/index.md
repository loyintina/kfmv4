# behavior-injection · 研究线登记（行为注入包）

> 2026-08-03 立。构想：**把经过验证的高质量行为模式（如洛主思维模式/证据纪律/
> 讨论启发式）提炼成模块化「行为注入包」，问题提出时拼进上下文——弱/中模型
> 通过模仿涌现出接近强模型的行为**。定位：研究设计（.kfmv4 面孵化），成熟后
> 结晶进 kfmv4 正式机制（prompts/global 或工作流）。

## 研究假设（待实验验证）

H1 **补强假设**：同模型下，「有行为注入包」的讨论/任务质量显著高于「无注入包」。
H2 **差距弥合假设**：弱模型 + 好注入包 ≈ 强模型 + 空上下文（行为质量 = 模型 × 上下文）。
H3 **模块化假设**：注入包可组合（证据纪律 + 讨论模式 + 领域规则 叠加），组合
   效果可测量、可优化。
H4 **退化边界**：注入包对强模型收益递减甚至负收益（Anthropic「减法」信号——
   强模型被硬规则过度约束）。

## 复用基础设施（已实战验证，2026-08-03 161 臂判卷）

| 能力 | 现成组件 | 本研究的用法 |
|------|---------|-------------|
| 自动化 agent 批跑 | `agent-runner.mjs`（provider 兜底链）+ subagent 集群（AgentSwarm） | 同模型 × 有/无注入包 × N 任务 批量跑 |
| 脚本化管线 | `experiments/coldstart/tools/*.mjs`（batch 模式/并发/断点续跑） | 注入包变体生成 → 批跑 → 判卷 |
| 判卷尺 | coldstart 判卷体系（judge/幻觉/溯源） | 需新「行为质量判卷尺」（讨论质量维度，非探索质量） |
| 数据分层 | `.kfmv4/experiments/<线>/`（arms/transcripts/scores） | 同构 |
| 观测 | `obs-aggregate.mjs` | 可扩展注入包效果周报 |

## 注入包候选源（第一批）

1. **证据纪律**（prompts/global/evidence-discipline，已验证有效——面板编造率下降）
2. **思维模式**（thinking-patterns 10 模式 → 讨论启发式 prompt）
3. **讨论启发式**（类比驱动/找反例/追问本质/拆轴 → 讨论行为注入包）
4. **工作流精髓**（doc-write/检查纪律 → 任务行为注入包）

## 实验设计（待细化）

- 变量：模型（强/弱 2 档）× 注入包（无/单/组合 3 档）× 任务（2-3 类）
- 对照：同模型空上下文基线
- 判卷：行为质量尺（讨论维度：类比质量/反例发现/本质追问/结构化）
- 输出：行为差距矩阵 → 验证 H1-H4

## 边界（已知）

- 模仿 ≠ 内化：注入包是「行为租借」，每次问题提出时拼入，不改变模型权重
- 负迁移风险：弱模型忠实模仿注入包错误 → 注入包质量须经 check 级检验
- 上下文成本：注入包必须精选（必读清单越长越被跳读）
- 价值递减：模型代际变强后注入包收益下降（定位：经济模型 × 中低能力区间）
