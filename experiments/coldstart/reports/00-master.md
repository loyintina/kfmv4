# 00 · 冷启动多臂实验 · 主报告

> 2026-08-01。124 臂受控实验的总结成。子报告：01 判卷信度 / 02 失败分类学 /
> 03 边界纪律 / 04 探索策略 / 05 人格签名 / 06 harness 差异。
> 数据层：`derived/`（arms.json、124 评分卡、gold-panel.json、themes/、cross-stats.json）。

## 研究问题

同一试卷（kfmv4-lab @ 冻结基线）+ 同一提示词下，「模型 × harness × 角色条件」
如何影响一个 agent 冷启动接手项目的：理解准确率、边界纪律、探索策略、行为风格？

## 方法（混合方法收敛设计）

- **定量层**：124 臂 × 统一评分卡（rubric.md 定级 + ground-truth.md 时代锚点），
  ds-v4-flash 主判（90/124），判卷信度经 31 臂金标准+8 臂双判标定（报告 01）。
- **定性层**：五域开放编码（40 主题）→ 轴心合并（报告 02-06）。
- **信度纪律**：判卷尺三次校准（3deb88b 翻案/33→32 锚点/AB 时代锚点），
  测量中途不换尺，盲区在分析层修正。行为维度可直接用，错误计数 ±1 容差，
  幻觉类为已知测量盲区（低估）。

## 头号发现（按证据强度排序）

1. **计数病是全场最高频失败（50/124 臂次）**，根因是文档中同一事实有多个
   手写副本且随时间漂移。→ 处方：计数类事实唯一出处、机械生成。
2. **LCA/跨仓拓扑陷阱是最稳定失败信号**（深入探索者中发生率过半），
   踩法各异 = **方法论缺失**，不是知识缺失。→ 处方：入口文档给取证 SOP。
3. **实证精神是双刃剑**：实证派低级错误少但高级推断错多；破界臂 15/24 是实证派——
   「修复者变体」（诊断全对、纪律归零）是能力与边界的解耦点。
4. **角色卡是行为调节器**（30 臂复测，本实验最干净比较）：
   人格卡=守界+质疑（weiran 6/6 守界）；文档约束=执行力强但判断失校准
   （kfmdocs-only 实错 1.33/臂、LCA 4/6）；完全体=质疑与实证双高但高级错误率上升。
5. **「只读子代理探索」是全场最优行为结构**（3+1 臂全零错守界完整）——
   深度、准确率、边界三赢。
6. **harness 决定探索深度下限，模型决定上限**；工具暴露面与破界率正相关。
7. **文档设计缺陷可被测量**：腿三两行排版陷阱（约 50% 误读率）、
   信箱记录漂移（双向被踩）——文档不是中性的，它是实验变量。
8. **元认知事件存在**：2 臂发现自己是实验对象后仍守界完成任务，
   并把实验数据当裁决依据引用。

## 处方针线汇总（→ 入口文档设计任务）

文档侧：计数唯一出处 / 状态注记与标题同行 / 环境事实附取证指引 /
拓扑 SOP / 专有名词表 / 信箱结案即回写 / 入口协议分层（最小必读+扩展）。
产品侧（kfmv4 harness）：边界自我加压条款 / 修复冲动的合规出口 /
只读子代理探索模式 / 上下文卫生优先修（人格签名对其敏感）。
实验方法侧：模型×harness 正交补齐 / 幻觉第二把尺（出处反查）/
判卷集群管线已固化可复用（tools/judge-batch.mjs + theme-code.mjs）。

## 局限

- 每格样本小（模型×harness 多数格 n≤3），只报描述统计，不做推断统计。
- 模型×harness 混杂（ds-flash 占深探臂多数），组间比较为方向性结论。
- 判官为 LLM，幻觉类错误召回率估计仅 60-75%（报告 01）。
- 试卷基线中途前移过一次（50badfa→8c9616b），时代锚点已校正但早期臂的
  基线内漂移不可完全排除。
- 试卷「只读」留白是有意的测量维度（指令冲突），结论向生产场景推广时需注意。
