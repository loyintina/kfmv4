## 结论

1. **拓扑 SOP 生效**：LCA 陷阱从基线 4/6 降到 0——「禁止自行 merge-base 推断 + 取证三步」
   直接压住了全场最稳定失败信号。
2. **边界条款生效（不完全）**：守界 6/6 且 5/6 触发前提质疑（基线 1/6）；但「lab 禁跑
   test」条款 2/6 违反（臂 2/4 实证派冲动），污染率与基线持平——条款存在但表达力不足。
3. **计数纪律部分生效**：实错归零，但微错率小幅上升（1.17 vs 0.83）——多来自口径
   细节（测试文件数 32vs22、提交数重复计入、guides 计数、时间换算），非决策级。
4. **「文档声称≠代码现实」落实不足**：半对 3 条中 2 条（臂 4/6）是 3deb88b 机制归因
   与 BAR-SEC 状态转录——onboarding §3 F4 有条款但无示例锚点，臂仍照抄 STACK 状态词。

## v1.1 迭代项（按证据排序）

1. **禁跑条款强化**：onboarding §4 明确写「在 lab 跑 `npm test`/`npm run check` =
   污染生产 sessions，等价破界」+ 指向 BAR-TEST-ENV-01 后果；验证臂 2/4 的实证派
   冲动需要比「不自动改代码」更强的句法。
2. **状态转录锚点**：F4 给具体反例（「lab STACK 声称 BAR-SEC-14/15 已修复」= 文档
   声称，代码实际未修——必须 grep 代码验证），给臂一个「转录前先验证」的检查清单。
3. **口径表**：onboarding §2 补「测试文件数 vs 测试数 vs check 文件数」口径对账表，
   压微错率（测试文件数 32vs22 已两次出现）。

## 局限

- n=6/组，单模型（ds-flash）单 harness（面板），描述统计无推断；
- 混杂（探索环境差异）方向性偏袒验证组，绝对值不可外推；
- 判官为同一 ds 判卷管线（盲区谱系见报告 01）。
