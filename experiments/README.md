# experiments/ — agent 行为实验环境

> 这里存放**实验**，不是测试。`tests/` 回答「代码对不对」（确定性断言，非 0 即 1）；
> `experiments/` 回答「agent 行为好不好」（统计性观察，需要判卷、需要地面真相、允许分歧）。
> 混在一起会模糊两者的语义，所以实验是顶层目录，与 tests 平级。

## 通用实验契约（v0.1）

实验的形式、流程、方法可以完全不同——这个契约不规定实验**怎么做**，只规定任何
实验目录必须能回答六个问题。契约是**角色**，不是模板：文件名可以变，角色必须在。

| 角色 | 必须回答的问题 | coldstart 实例 |
|------|----------------|----------------|
| **协议 protocol** | 每一臂怎么跑？什么被逐字冻结？变量矩阵是什么？ | `prompt.md` |
| **环境 environment** | 受控对象是什么？它的已知缺陷/陷阱有哪些？卫生流程是什么？ | `paper.md`（试卷=/root/kfmv4-lab） |
| **地面真相 truth** | 判对错依据的事实是什么？怎么刷新验证？ | `ground-truth.md` |
| **评判 rubric** | 定级标准是什么？判卷尺被校准过吗？ | `rubric.md` |
| **数据 data** | 原始记录在哪？（不可变，结论必须能回溯原文） | `sessions/`——存 `.kfmv4` 私有同步区（见下「两层数据」） |
| **索引 index** | 每一臂一行，机检引用完整（check-experiment-index） | `index.md` |
| **报告 reports** | 结论是什么？每条结论挂了哪几条臂做证据？ | `reports/` |

## 两层数据（2026-08-01 用户拍板）

- **开源层**（本仓库）：协议、试卷定义、地面真相、判卷标准、索引（含逐臂尸检结论）、报告。
- **私有层**（`.kfmv4/experiments/<实验>/sessions/`，随 `.kfmv4` 定时推送私有仓库）：
  原始答卷原文。含人格卡、内部基础设施细节，不进公开仓库；
  私有同步保证不丢失。index.md 的 `sessions/xxx.json` 引用由
  check-experiment-index 在本机数据区解析验证（开源克隆无数据区则跳过）。

## 原则

1. **单一出处**：原始答卷只活在 `.kfmv4` 私有同步区；结论与索引只活在仓库。互不复制。
2. **原始数据不可变**：答卷归档后不再修改；发现判卷错误时改的是 index 行和 rubric，不改原文。
3. **结论必须挂证据**：报告里的每个判断引用臂 id；不挂证据的结论不入库。
4. **判卷尺也要被校准**：ground-truth 是易腐资产，每次判卷前按文档里的方法刷新；
   校准事件记入 rubric（已有两案：3deb88b 翻案、33→32 check 锚点）。
5. **模式从撞墙中演化**：本契约 v0.1 提炼自唯一一个实验（coldstart），
   刻意留白。新实验带来新形态时，先撞墙、再把撞出来的经验回写这里升版——
   不要预先设计没被撞过的需求。（2026-08-03 已有 3 实验线：coldstart /
   harness-studies / behavior-injection，契约角色由各线自填。）
