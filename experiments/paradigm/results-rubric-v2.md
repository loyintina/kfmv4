# 判卷尺 v2：锚定量尺——验证与 v1 对比（2026-08-05）

> 动机：v1 尺（0-3×4 维，无锚点）实测满分率 51%，顶部差异被压死，
> 「opus/luna 满分饱和、范式包无增益」的结论无法区分是真实饱和还是尺子封顶。
> v2 = 锚定 0-5×4 维 + 特征清单（exclusions / has_uncertainty /
> has_failure_condition / has_self_rating），实装于 judge-llm.mjs `--rubric v2`。

  （不知臂的实验条件与 v1 分），原始选择 `/tmp/rubric-v2/<dim>/anchors.json`，
  映射 `meta-pool/mapping.json`。

  找不到干净实例（最差的臂也有零星元认知词），锚点表相应档位置 null，
  判卷时该档按「低于 1 档锚点」语义处理。
- reasoning_visible 的 0 档锚点实为 1 档水平（c09 臂），已在锚点表注明——
  该维真实 0 档同样无实例。

## 判别力验证（631 臂全量重判，归档 meta-pool/judge-e11-e12-v2-flash.json）

| 指标 | v1（0-12） | v2（0-20） |
|---|---|---|

| 中位数 | 11 | 14 |
| 分布 | 11-12 两格装走 76% | 2-20 展开，峰在 11-12（各 ~17%），双尾 |

- **方向保持**：D≥B（重复 ≥ 单遍）v1 为 8/10 槽（仅 2 个不饱和模型可比），
  v2 为 **15/19 槽**（4 模型全可比）——g3p-think 5/5、opus 4/4、luna 3/5、
  g2.5-pro 3/5（1 平）。已知结论方向没有被新尺推翻。
- **格间/格内方差比** 0.28-0.45：格间差异约为臂内噪声的 1/3，n=8 下
  单格均值仍有 ±0.7-1.1（0-20 尺）抽样误差——定量结论仍需更大样本，
  与 v1 结论一致。

## v2 带来的结论修正（重要）

**v1 结论 1「opus/luna 满分饱和，范式包对强模型无增益空间」部分是尺子伪影。**
v2 下 opus 不再贴顶：A 无包 16.25（全场最低槽）→ B-8.1k 18.00 → D 档 18.9-19.4，
**增益明确可见**；luna 同样从 A 12.38 到 C-65.1k 15.25。「强模型饱和」
降级为：强模型增益幅度小于弱模型预期，但并非零——**强模型烧臂不再是纯浪费，
是否继续取决于增益斜率是否值得成本**。
