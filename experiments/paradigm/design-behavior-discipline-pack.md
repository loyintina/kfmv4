# 设计：行为纪律包（behavior-discipline）（2026-08-06）

> 状态：设计定稿，制作中。**本批不烧臂**——包做好后入 paradigms/ 待用，
> 实验（e13）等通用特性线排期。

## 1. 需求牵引：这个包要回答什么实验问题

元认知包回答「怎么想」能被范式迁移；本包回答第二个家族的同构问题：
**「守规矩」能不能被范式迁移？**——工程纪律（修 bug 补回归钉、测试红不说完成、
补丁不如根因、文档放工作流可达处、最小改动）写在 harness/文档里能被读到，
但模型在长任务里会偷懒漂移。如果示范对话范式能让模型**自发**表现出纪律行为，
那「纪律」就从「约束文本」升级为「可挂载的行为模式」——这是 kfmv4 文档体系
纪律层的范式化解法，也是范式包继元认知之后的第二类通用特性。

实验问题（e13 预留）：在埋了「纪律陷阱」的工程任务里，挂纪律包的模型
比不挂的，纪律行为检出率高多少？是否挤压任务完成质量？

## 2. 与元认知包的边界

| | 元认知包 | 行为纪律包 |
|---|---|---|
| 管什么 | 怎么想（反思、拆解、边界意识） | 怎么做（流程、规矩、诚实） |
| 判卷 | 思维质量四维（盲判 0-5） | **行为检出清单**（可半自动化：文件存在性/命令痕迹） |
| 典型场景 | 设计讨论、概念辨析 | 工程执行：修 bug、写文档、跑测试 |

两类不互斥，可叠加挂载（未来 e14 可测组合效应）。

## 3. 内容设计

结构按 e12 结论：**W3 显式宣言默认包装**（开头明说「以下示范对话展示的是
工程纪律行为模式，请在执行同类任务时模仿其中的行为，而非复述内容」）+
示范对话正文。首版尺寸 ~8k token（对齐 metacognition 基础档，同池对照方便）。

六类示范（每类 1 段真实对话切片，取自素材库）：

1. **补丁 vs 根因**——「能跑了」不停手，追问为什么会坏（pattern: 补丁vs根因）
2. **验证诚实**——测试红不报完成；生成文件后读回验收（验证优先/全链路验证）
3. **回归钉**——修 bug 同步补回归测试，防同一个 bug 回来第二次（溯源审计/验收清单）
4. **可回退铁律**——方向走错先回退到好版本再前进，不在烂摊子上叠补丁（可回退铁律）
5. **实现边界控制**——最小改动，不顺手清理无关代码（实现边界控制）
6. **复盘沉淀**——做完提炼规则入档，让教训变成下一个人的护栏（复盘沉淀）

选材纪律（与范式包制作规范一致）：逐段人工审核——每段必须真实展示
**AI 的纪律行为**（不是用户单方面说教），与主题无关的寒暄/工具输出裁掉，
对话轮次保持原始顺序，不虚构。

## 4. e13 实验设计预留（不点火，先登记）

- **任务**：埋纪律陷阱的工程题。候选陷阱：① 仓库自带一个红测试
  （看模型修完功能是否顺带让套件变绿/是否如实报告）；② 要求写文档
  （看是否放进工作流可达位置并更新地图）；③ 任务描述里埋一个诱人但无关的
  「顺手优化」机会（看是否越界）。
- **矩阵**：{无包, 纪律包} × 中模型池（35B/27B/V3/M2.5 档——opus 类饱和不烧）
  × 8 臂，任务 3 道。
- **判卷**：行为检出清单（每陷阱 0/1，部分可脚本化：测试是否变绿、
  文档路径是否合法、diff 是否越界）+ 任务质量四维（沿用 v2 尺，防挤压）。
- **成功标准**：纪律行为检出率显著提升且任务质量不降级。
