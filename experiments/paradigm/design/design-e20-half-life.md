# e20 版本半衰期 · 设计（2026-08-07 傍晚）

> 核心问题：范式包效应是**长期资产**还是**快消品**？
> 服务商会静默升级模型（权重/数据/对齐，版本号都不一定变），
> e17~e19 的全部结论严格说只对"当前模型快照"成立。
> e20 用冻结锚点矩阵定期重跑，测效应随时间的衰减速率。

## 2. 每个 wave 的操作规程

1. 复制 spec：`specs/e20.json` → `specs/e20w{N}.json`，把三处
   `e20w1` 改成 `e20w{N}`（experiment / prefix / judge.out 的键与文件名），
   其余字段**一字不动**。
2. `--check` 校验后点火（后台，timeout 4h）。判卷自动接。
3. 用 aggregate-e19.mjs 同款格均值算法（或 recompute-cells.py）出五格均值，
   与 §1 基线并排，写 `results-e20-w{N}.md`（格式：基线 vs 本波，
   每格每维 Δ，meta/bd 两主效应的 MWU p 值）。
4. index.md 结果登记行加名字，过 check-experiment-registry，提交。

触发节奏（满足其一即开新 wave）：

- 距上一 wave ≥ 30 天；
- 日常使用中察觉 v4-flash 行为异常（风格突变、判官口径漂移）；
- DS 官方公告模型更新。

## 3. 判读规则（预注册）

- **效应存活**：meta 包 dissect 相对无包仍显著为正（方向一致即可，
  p 要求放宽到 <0.10，n=8 功率约束）。
- **效应衰减**：主效应方向不变但幅度缩到基线的 50% 以下 →
  记"半衰期到达"，该波起所有挂载建议降一级可信度。
- **效应死亡/倒挂**：主效应消失（|Δ|<0.2）或方向反转 →
  该包结论作废，回炉重新标定；若是判官口径漂移导致（判官自身
  基线格也漂移），先换判官重判再裁决。
- **判官自检**：无包格是本波判官口径的探针——无包格漂移而
  包间差不变，是判官问题不是模型问题，结论区必须分开写。

## 4. 与其他实验的关系

- 不重跑 e19 全梯度：半衰期关心的是"效应是否还活着"，
  一个峰值锚点足够，40 臂/波的成本可以月月跑。
- 若某波发现死亡/倒挂且确认非判官问题，触发重新标定专项
  （编号 e21+，届时立项），不是 e20 的职责。
- C 挂载开关落地后，e20 曲线是面板挂载建议的保鲜背书。
