## 一、判定（什么是范式包）

沿用 index.md：范式包 = **可模仿的示范**（完整思维过程/行为模式节选），AI 从
示范中抽象模式并泛化（改变能力结构），不是逐条遵守规则（约束）。规则包
（如 evidence-discipline，1.8KB 约束清单）**不是**范式包——它可作为范式包的
约束层（范式包 = 示范 + 可选约束），但不是范式本身。

## 二、首版规格参数

| 维度 | 规格 | 依据 |
|------|------|------|
| 长度 | **8k-16k token**（中文约 10k-20k 字符；首版目标 ~8k token） | H5 甜蜜区（32k-128k token）下沿采样；<8k token 话题对齐不足（「太小不算范式包」）；首版成本可控，后续梯度加长验证倒 U 形。⚠️ 2026-08-04 修正：H5 是 token 维度，早期误写「8k 字符≈2k token」换算错误（中文 8k 字符 ≈ 6k+ token） |
| 结构 | **S2 无缝拼接**——高纯度自然对话节选 | 同化最自然；直接复用长会话素材（无需重新组织） |
| 纯度 | 高思维密度：去寒暄/去重复/去低信息量轮次 | H6：同长度下高密度节选 > 完整对话 |
| 内容构成 | ≥1 个完整思维轨迹（问题→拆解→证据→结论/修正） | 可模仿性的前提（index.md 判定标准） |
| 素材 | 本会话（kimicode 高级元思考）为主 + qoder/omp/opencode 长会话扫描 | 2026-08-04 定稿 |

## 三、验收标准（每个范式包出厂前逐条过）

1. **长度达标**：8k-16k token（中文约 10k-20k 字符；首版 ~8k token）。低于 8k token 不算范式包，退回「提示词」
2. **完整思维轨迹**：含问题提出→拆解→证据核查→结论/修正的完整来回
   （不是观点罗列，是有推导过程的示范）
3. **高密度**：信息量/字符比高，无填充段、无寒暄
4. **自包含**：不依赖外部上下文（不引用本会话前文/项目外知识）也能理解范式
5. **无噪音**：不含与范式无关的闲聊/重复/工具执行细节（工具调用可保留
   结论性部分，不保留过程噪音）
6. **负迁移防线**：示范中的行为本身正确（错误的示范会教坏弱模型——index.md
   边界「负迁移风险」；出厂前人工复核示范无错误行为）

## 四、制作工艺（从长会话提取）

```
1. 定位：扫描会话记录（wire.jsonl append_message），找高思维密度段落
   （决策/证据核查/架构讨论的特征：推理动词 + 证据引用 + 修正）
2. 切片：按思维模式类型切（index.md：同一素材可切多片——决策/讨论/元认知）
3. 去噪：去寒暄/重复/低信息量轮次（S2 保留自然对话形态，但剪掉废话）
4. 质检：验收标准 1-6 逐条过
5. 入包：.kfmv4/paradigms/<名>.md（首行 # 名 + 一句话范式定位）
6. 登记：experiments/paradigm/index.md 数据区臂清单 + 本文件批次记录
```
