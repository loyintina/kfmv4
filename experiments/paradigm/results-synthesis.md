# 范式包研究 · 综合分析（2026-08-07 晚）

> 范围：e1~e20 全部实验，20 份结论文档，8 个正式假设 + 2 个候选假设的裁决。
> 累计样本：3000+ 臂，14+ 模型（硅基小模型池 / 聚光强模型池 / DS v4-flash 主力），
> 判卷体系 v1→v2 锚定尺，判官偏差已标定（Δ=+0.19/12）。
> 本文是顶层综合：每条结论标注证据链与置信等级。

## 一、一句话总结

**范式包是真的、有条件的、可工程化的**——它能稳定改变模型行为，
但只在特定能力域、特定长度、按模型体质配对时有效；
它不是咒语，是一种有剂量-效应曲线、有半衰期、有适用症的技术资产。

## 二、核心结论（按置信度排序）

### A级：多实验复现、统计显著

**A1. 有效域边界：只对「知道但不主动显化」的能力有效。**
已内化的通用素养（如"先查根因再打补丁"）挂包零增益（e1/e4：16/16 全对，
任务零区分度）；元认知这类"会但不主动做"的能力，效应翻倍
（e5：2.3→4.5；mm3 3.5→9.0，分布无重叠）。
→ **选包主题的第一纪律：别教模型已经会的事。**

**A2. bd 包对自我解剖（dissect）的效应为真。**
e14b 单实验 p=0.002，e17 单实验不显著（p=0.178），
合并 n=64/格 p=0.0016——**这是项目复现次数最多、检验最严的效应**。
诚实注记：效应量 +0.3~0.4/5 分，是"稳定的小效应"，不是开关。

**A3. 长度上限 32k，断崖在 3%→13% 占用率之间。**
e18c（倒 U，甜点 32k）与 e19（断崖+高原）两系语料同向：
越过 32k~128k 区间一次性退化（p=0.009/0.002），之后到 51% 占用完全脱敏。
dup 对照证明高原区不是内容稀释也不是占位成本，是模型处理方式的相变。
→ **制包工艺铁律：精选 32k，不做巨型包。**

**A4. 挂载生命周期：跳变真实、摘除不塌、无疲劳、摘除有短期晃动。**
px 三连实验：挂载提升 +2.62/15 真实；摘除后残留 +1.40（保留 53%），
观测窗内不衰减；持续挂载 13 轮零疲劳；摘除代价是 1-2 轮不稳定。
→ **挂载策略：按需挂上，挂上就别频繁摘。「用完即摘省 token」是负优化。**

**A5. 模型强度 × 包类型交互（倒挂）。**
弱模型池的冠军是 bd（行为纪律）；v4-flash 上 bd 只剩方向性，
meta 元认知包四维全线最高（dissect p=0.004）。机制自洽：
强模型纪律本就好，可挖的层在元认知。
→ **给什么包，先看模型是谁。**「bd 有效」不可外推为主力模型挂载建议。

### B级：单实验显著或大规模分析支撑

**B1. H2 差距弥合分层成立。** 35B+8.1k 包（16.50）摸平 opus 空基线（16.25）；
27B/M2.5 超过三个非顶配强模型空基线；V3/R1 等未弥合。
且弥合不对称——强模型自己挂包后差距重开（opus 挂包 18-19.75）。
→ 范式包是**中模型的杠杆**，不是弱模型的救命绳，也不是强模型的禁品。

**B2. 组合无协同（H3 否决）。** bd+meta ≈ bd（p=0.633），主场外有稀释方向。
→ **1+1=1。按场景挂单包，多范式轮换而非拼接。**

**B3. 注入位置不重要（e15）。** system/first-user/pre-task-user 无显著差异。
同化发生在内容不在挂载点。→ **默认 pre-task-user（缓存友好免费档）。**

**B4. 包装影响纯度不影响深度（e12+matrix-v2）。** W2 轻标记压复述癖
（g2.5-pro 污染 60.0→10.4）；扩池后 W3 显式宣言最频繁登顶，无全场最优。
内容结构（S2 无缝/S5 对比/S6 复盘）在行为任务上全部噪音带（e16）。
→ **包装看模型体质选，内容结构不用纠结。**

**B5. 重复是稀释的解药（H8）。** 高占用退化区，复制追加版救回 +4.00
（M2.5、R1 同向六模型）；65% 占用内平台 +0.4 无衰减。
（注：此结论来自 131-262K 窗口池；v4-flash 1M 窗口下断崖大幅提前，
两读数不矛盾——占用率拐点随窗口规模前移。）

### C级：方向性、未裁决、悬案

- **C1. H6 纯度假设未直接验证**：浓缩×2 与单遍打平，专项对比欠奉。
- **C2. H10/H11 候选悬案**：g2.5-pro 复述癖机制、opus W2 凹陷机制，
  跨尺稳定的现象，机制未查。
- **C3. e13 的 T1「bd 更差」信号已被 e14a 复现否决**（噪音实锤）——
  档案级教训：单次方向性信号必须复现才能入库。

## 三、方法论资产（比单条结论更值钱的部分）

1. **判卷体系**：v1 尺的"强模型饱和"被证明是尺子封顶伪影（满分率 51%→v2 10.3%）；
   判官自判允许但须标 Δ；跨模型比绝对分不可信，主分析一律模型内部比。
2. **harness 伪影**：零分臂 4.8% 是伪影且是小模型专属病（Ling 53%/GLM-Z1 33%）——
   小模型的低分要重读为「harness 存活率」，不看存活率的占用率分析会读出假拐点。
3. **复现纪律**：e13→e14a 的噪音否决、e17 单实验不显著→合并显著的两次教训，
   确立了「单实验方向性 ≠ 结论，合并/复现才算数」的入库标准。
4. **预注册与触发式实验**：e19 的异源对照触发条件未触发即不开，省 token 也省结论污染。
5. **e20 半衰期监测**：锚点矩阵冻结 + 噪声地板 |Δ|≤0.5 标定，
   所有上述结论现在有了保质期探头（wave 触发：30 天/异常/官方公告）。

## 五、如果只能记住五句话

1. 范式包有效，但只教得动「知道但不主动做」的事。
2. 32k 是包长上限，巨型包已证伪。
3. 弱模型吃纪律包，强模型吃元认知包——给包先看模型。
4. 包不能拼，只能轮换；挂上就别老摘。
5. 所有结论有保质期，e20 每月盯着。
