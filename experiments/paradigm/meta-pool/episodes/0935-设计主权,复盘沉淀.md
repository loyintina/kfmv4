| 移除 | 原因 |
|------|------|
| Model 下拉框整行 | Model 选择是配置卡/面板的事 |

| `updateModelSelect()` 函数 | 随 Model 下拉框一起移除 |

**角色卡** — 同样的去激活化：

| 移除 | 原因 |
|------|------|
| `saveActiveRoleId()` / `loadActiveRoleId()` | 不再写 `active.json` |
