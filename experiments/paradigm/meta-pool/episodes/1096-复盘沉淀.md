## 📚 Pretext 专门讲解

### 一、Pretext 是什么？

**Pretext** 是一个纯 JavaScript/TypeScript 的**文本测量与布局库**，由 @chenglou 开发（MIT 许可）。

**核心价值**：在不触碰 DOM 的情况下，精确计算多行文本的布局（高度、行数、每行内容）。

---

### 二、为什么需要 Pretext？

#### 问题背景
KFM v2 使用 **Canvas 渲染引擎**（而非 DOM），需要自己处理：
1. **文本换行** — 给定最大宽度，自动折行
2. **高度计算** — 算出文本框需要多高
3. **CJK 禁则处理** — 中文标点不能出现在行首/行尾
4. **Emoji 支持** — 宽高与普通字符不同
5. **混合语言** — 中文、英文、阿拉伯语混排

#### 原生 `measureText` 的局限
```javascript
ctx.measureText('Hello').width  // ✅ 单行宽度
// ❌ 无法自动换行
// ❌ 无法处理 CJK 禁则
// ❌ 无法处理混合语言断行
```

#### DOM 测量的代价
```javascript
const div = document.createElement('div')
div.textContent = longText
div.style.width = '200px'
document.body.append(div)
div.offsetHeight  // ❌ 触发 layout reflow（性能杀手）
```

## 🎨 Canvas 和 Pretext 是做什么的？

### 一、Canvas：你的"数字画板"

**想象一下：**
你有一个**透明的画板**（Canvas），用毛笔在上面画：
- 画一个方框代表文件
- 写几个字代表文件名
- 涂颜色表示选中状态

**在 KFM v2 里：**
```
整个手机屏幕 = 一块大画板
文件树       = 在画板上画很多小方框 + 文字
文件预览     = 在画板上画文件内容
AI 对话      = 在画板上画对话框 + 聊天气泡
```

**为什么要用 Canvas 而不是直接写 HTML？**

| 方式 | 像什么 | 问题 |
|------|--------|------|
| **HTML + CSS** | 搭积木（每个文件是一个 div） | 文件多了（1000+）会卡成幻灯片 |
| **Canvas** | 在一张纸上画 everything | 文件再多也流畅（只画屏幕上可见的） |

**简单说：Canvas 就是 KFM v2 的"渲染引擎"，一切可见的东西都是画出来的。**

---

### 二、Pretext：Canvas 的"智能排版助手"

**问题来了：**
Canvas 会画画，但它**不会自动换行**！

```javascript
// 你写：
ctx.fillText("这是一个非常非常非常长的文件名", 10, 50)

// 结果：文字直接画出屏幕外，看不见了 😭
```

**Pretext 解决的三个核心问题：**

#### 1️⃣ **自动换行**
```
输入：  "这是一个很长的文件名.txt"
限制：  框框宽度只有 100px
Pretext：切成多行
  第一行："这是一个很长的"
  第二行："文件名.txt"
```

#### 2️⃣ **计算高度**
```
问：这段文字需要多高的框框才装得下？
答：Pretext 算出来 = 3 行 × 20px = 60px 高
```

#### 3️⃣ **支持多语言**
```
中文："春天到了"    → 每个字都算宽度
英文："Hello world" → 单词整体算宽度
Emoji："😀"         → 特殊宽度
混合："Hello世界😀" → 混在一起也能算
```

**没有 Pretext 的后果：**
- 文件名太长显示不下，需要自己写换行算法（难）
- 中文标点不能出现在行首（禁则）要自己处理（更难）
- 英文单词被从中间拆开（体验差）

---

### 三、它们俩怎么配合？

**工作流程（以文件树中的文件名显示为例）：**

```
1. 准备阶段（只做一次）
   文件名 = "2026年春季项目计划最终版V3.docx"
   字体   = "14px 黑体"
   ↓
   Pretext 分析：
   - 分词：["2026年", "春季", "项目", "计划", "最终版", "V3.docx"]
   - 测量每个词的宽度
   - 记住结果（缓存）

2. 布局阶段（每次框框大小改变都做）
   给定：框框最大宽度 = 120px
   行高 = 20px
   ↓
   Pretext 计算：
   第一行：["2026年春季", "项目"]  总宽 118px ✓
   第二行：["计划最终版", "V3.docx"] 总宽 115px ✓
   ↓
   结果：需要 2 行，总高度 = 40px

3. 绘制阶段（Canvas 上场）
   Canvas 根据 Pretext 告诉你的结果：
   - 在 (x, y)     画第一行 "2026年春季项目"
   - 在 (x, y+20)  画第二行 "计划最终版V3.docx"
   - 画一个底框，高度 40px
```

**一句话总结：**
> **Pretext 是"大脑"（计算怎么摆），Canvas 是"手"（实际画出来）。**
