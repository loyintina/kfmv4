## 4. 结论

1. **纪律包在主场有效（方向性）**：T2-b 文档归位率 6.3% → 18.8%（三倍），
   且 T2 的 meta_depth 边际上升（p=0.076）、T2-d 声明工作流方向为正。
   「包×任务类型匹配」方向成立——行为纪律包教得动它示范过的纪律
   （文档归位），这是包里六节之一的直接对应物。
2. **不泛化**：T3 改动守界上纪律包与对照无显著差异（T3-a 37.5% vs 25.0%
   反为噪音级倒退；T3-c 双零地板）。包里没有对应示范的纪律维度，
   挂包与不挂包一样踩陷阱——「同化」是具体的，不是晕轮式的。
3. **T1 上纪律包反而更差（方向性，双通道互证）**：脚本通道外两条独立证据
   同向——v2 质量分 meta_depth / reasoning_visible 偏↓（p 0.16~0.19），
   语义项 T1-b 如实报告红测试 61%→36%（p=0.108）、T1-c 完成声明一致
   79%→57%（p=0.152）。一个可能的机制：纪律包示范的是「做对的样子」，
   中弱模型同化后更倾向于**表演做对**（声明完成）而非**报告没做对**
   ——包的「诚实汇报失败」示范没能抵消「展示成功」的引力。与 H4 修订版
   同向（中弱模型挂包有质量成本），e14（4 包 × 2 任务 × 8 重复）复核。
   **【2026-08-07 修订】本条被 e14a 同尺复现否决**：e14a 的 T1-b 方向反转
   （59%→74%，p=0.51），两次独立实验方向相反 = 原信号是噪音。裁决表述：
   T1 上 bd 与对照**无稳定差异**。详见 results-e14-combination.md §2/§4。
4. **T3-b / T2-c / T1-d / T3-c 无区分度**：两个天花板、两个地板——
   这四个检项对未来实验没有测量价值，e14 起只作存档不作读数。

## 5. 判卷基建教训（本轮新沉淀）

- **ti 撞名**：e13 三任务共享 `e13-t0` 前缀（ti 跨 batch-run 调用重置），
  e11 哈希后缀只防同任务撞。judge-llm 已加任务文本匹配分流（臂入库 task
  原文 vs --task-file）。教训：**一个实验一个前缀**，spec 化后已由 exp-driver 保证。
- **语义键依从率**：deepseek-v4-flash 对 JSON 模板尾追加键的依从率约 30%/轮，
  强化「必出键」措辞后约 50%/轮。judge-llm 续判逻辑已改为「缺键即未判」，
  5 轮收敛到 T1 88% / T2 69% / T3 78% 后进入平台期（剩余臂多为极短/空输出，
  judge 稳定丢键）。未来判卷模板：**任务专属键放模板中段**（note 之前容易被截），
  或干脆每键独立一轮二值判定（成本换依从率）。
- **逃逸审计**：写监狱上线后 27 次越界写全拦截、0 泄漏
  （meta-pool/e13-escape-audit-post-jail.json）——写监狱实战验证通过，
  e14 起所有带 write 的实验默认开启。
