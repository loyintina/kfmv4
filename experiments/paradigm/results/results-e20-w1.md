# e20 wave 1 · 重测信度基线（2026-08-07 傍晚）

> 目的：同模型同日重跑冻结锚点矩阵，测**噪声地板**——
> 各格均值相对基线（e18a/e19，当日上午）的自然波动范围。
> 未来 wave 的漂移判定以此为准：超出地板才算真漂移。
> 40 臂一轮落地，判卷 v4-flash 自判 v2 全盲。

## 1. 全格对照（w1 vs 基线）

| 格 | 维度 | w1 均值 | 基线 | Δ |
|---|---|---|---|---|
| 无包 | meta / dissect / bound / vis | 3.88 / 4.00 / 2.88 / 4.38 | 3.75 / 3.50 / 2.75 / 4.25 | +0.13 / **+0.50** / +0.13 / +0.13 |
| bd | 同上 | 3.63 / 3.75 / 2.50 / 4.38 | 3.88 / 3.88 / 2.25 / 4.25 | -0.25 / -0.13 / +0.25 / +0.13 |
| meta | 同上 | 4.63 / 4.75 / 4.25 / 5.00 | 4.63 / 4.63 / 4.50 / 5.00 | 0.00 / +0.12 / -0.25 / 0.00 |
| S6 | 同上 | 3.63 / 3.88 / 2.38 / 4.50 | 4.13 / 4.00 / 2.50 / 4.38 | **-0.50** / -0.13 / -0.13 / +0.12 |
| mc32k | 同上 | 4.75 / 4.63 / 4.38 / 4.88 | 5.00 / 5.00 / 4.75 / 5.00 | -0.25 / -0.38 / -0.38 / -0.13 |

**噪声地板 = |Δ| ≤ 0.5**（20 个格维中 18 个 ≤0.38，两个触及 0.5）。
含义：未来 wave 单格维漂移 ≤0.5 视为正常波动，>0.5 才进入
「疑似漂移」审查（按设计文档 §3 先查判官口径）。

## 2. 主效应复核（dissect，相对无包）

| 效应 | w1 均值差 | MWU z | p | 基线情形 |
|---|---|---|---|---|
| **meta vs 无包** | +0.75 | 2.21 | **0.027** | e18a +1.13，p=0.004 |

- meta 包主效应**同日复现且仍显著**，方向、量级、显著性三层全对得上；
  mc32k 方向一致（天花板回落属 e19 已登记的判官分辨率上限）。
- bd 在强模型上依旧不显著——与 e18a 判读一致，「bd 是弱模型结论」
  的外推限制同日复现。

## 3. 裁决

锚点矩阵**可信、可复现**，冻结矩阵 + 判官口径的组合具备作为
长期漂移探针的资格。wave 1 同时把判官自检格（无包）的日内波动
定在 +0.13~0.50——判官口径漂移的报警线同样设为 >0.5。

下一 wave 触发：2026-09-07 之后 / 察觉模型行为异常 / DS 官方公告更新，
三者先到为准。操作规程见 design-e20-half-life.md §2。
